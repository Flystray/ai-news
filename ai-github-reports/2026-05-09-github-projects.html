UI UX Pro Max Skill

为 AI 编程助手提供专业 UI/UX 设计智能的开源技能包，内置 344+ 结构化设计资源

在 AI 编程助手迅速普及的今天，一个突出矛盾逐渐显现：AI 能写代码，但写不出好设计。绝大多数 AI 生成的 UI 代码存在配色随机、字体搭配不协调、忽略无障碍标准、风格前后不一致等问题。本项目通过一个结构化设计知识库，让 AI 编程助手在生成 UI 时能像专业设计师一样思考和决策。

📌 项目背景

AI 编程助手（Claude Code、Cursor、Windsurf 等）在代码生成方面已经相当成熟，但UI/UX 生成质量一直是短板。根本原因在于：AI 在生成 UI 时缺乏结构化的设计知识库可以参照。

传统解决方案是人工编写设计系统文档或购买设计库，但这两者都是"人读"的格式，AI 无法直接利用。UI UX Pro Max Skill 的创新之处在于：将设计知识以 CSV 文件形式结构化存储，通过 BM25 概率排名算法实现智能检索，当 AI 编程助手检测到用户在做 UI/UX 相关任务时，自动激活并注入相关的设计知识。

项目诞生于 2025 年 11 月，在不到 6 个月的时间里获得了 7.56 万星，反映了开发者对"AI 生成专业 UI"这一需求的强烈共鸣。v2.0（2026 年 3 月）新增了智能设计系统生成器和 161 条行业推理规则，进一步强化了自动化设计能力。

🚀 核心功能

  • 344+ 结构化设计资源数据库 — 67 种 UI 风格、161 套行业配色方案、57 组字体搭配、25 种图表类型、99 条 UX 指南，以及 v2.0 新增的 161 条行业推理规则，覆盖从 SaaS 到医疗到金融的各类产品设计需求。
  • 智能设计系统生成器（v2.0 旗舰功能） — 通过 AI 推理引擎分析项目需求，秒级生成完整的定制化设计系统规范，包括推荐布局模式（Hero-Centric、Feature-First 等 24 种）、配色方案、字体搭配建议、关键动效参数和反模式警告。
  • 自动激活与关键词检测 — 当 AI 助手检测到 UI/UX 相关自然语言请求时自动激活（如 "Build landing page"、"Design dashboard"），无需手动触发，无缝融入开发工作流。
  • BM25 智能搜索引擎 — 基于经典 BM25 概率排名算法实现的设计资源检索引擎，包含完整分词器、TF-IDF 评分函数和领域自动检测，能精准匹配复合设计需求（如 "SaaS 着陆页 + 信任元素 + 情感驱动"）。
  • 18+ AI 平台全覆盖 — 同时支持 Claude Code、Cursor、Windsurf、Codex CLI、GitHub Copilot、Gemini CLI、Kiro、Roo Code 等主流 AI 编程助手，提供统一的平台配置系统。
  • Master + Overrides 设计系统架构 — 采用"主模板 + 覆盖层"模式组织生成的设计系统规范，基础规范保存在 MASTER.md，页面特定覆盖规则保存在 pages/*.md，实现通用性与行业定制需求的灵活兼顾。
  • 预交付质量检查清单 — 设计系统实施完成后自动执行质量保证检查：无障碍性（对比度 ≥ 4.5:1）、性能优化（WebP/AVIF 格式）、交互规范（触控目标 ≥ 44px）、视觉一致性（间距统一）。

⚙️ 技术亮点

  • CSV 数据驱动的结构化设计知识库 — 与传统的"设计系统文档"不同，该项目将每一类设计知识都结构化为独立的 CSV 文件，通过 CSV_CONFIG 和 STACK_CONFIG 映射 10 个设计领域和 16 种技术栈。这种设计使设计知识可被算法检索、可版本控制、可由社区贡献，是"设计工程化"的创新实践。
  • BM25 算法在垂直设计领域的创新应用 — 项目在 scripts/core.py 中完整实现了 BM25 算法类，包括分词、文档频率计算、TF-IDF 评分和文档长度归一化。与传统全文搜索不同，该实现针对设计资源的短文本特征优化了参数（k1=1.5 控制词频饱和度，b=0.75 控制文档长度归一化），能精准匹配复合设计需求。
  • 双模式平台集成架构 — 创新地提供了两种集成模式：Skill 模式（适合 Claude Code、Cursor、Windsurf 等支持技能系统的平台）完整知识库安装，自动检测激活；Workflow 模式（适合 Kiro、GitHub Copilot 等平台）轻量引用安装，需手动斜杠命令触发。两种模式优化了不同平台的上下文窗口使用。

👥 适用人群

  • AI 编程助手用户 — 在使用 Claude Code、Cursor、Windsurf 等平台进行开发时，希望 AI 生成的 UI 具有专业设计水准的开发者。
  • 前端开发者 — 需要快速生成符合行业标准的 UI 代码，尤其在使用 React、Next.js、Vue、Svelte、Tailwind、shadcn/ui 等技术栈时。
  • 独立开发者和初创团队 — 没有专职设计师，需要快速搭建具有专业水准的 MVP 界面和 Landing Page。
  • 产品经理 — 需要为 AI 辅助开发提供设计系统指导，确保产品 UI 的一致性和专业性。

⚡ 快速上手

方式一：通过 npm/CLI 安装（推荐）

# 全局安装 CLI 工具 npm install -g uipro-cli # 进入你的项目目录 cd /path/to/your/project # 初始化（自动检测 AI 平台） uipro init --ai claude # Claude Code uipro init --ai cursor # Cursor uipro init --ai windsurf # Windsurf

方式二：直接在 Claude Code 中使用

# 安装 Skill 后，直接用自然语言描述需求 Build a landing page for my SaaS product with hero section, features, testimonials, and pricing table. # AI 会自动：① 检测产品类型 ② 推荐设计风格 # ③ 生成配色方案 ④ 输出完整设计系统规范
