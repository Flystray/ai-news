# GitHub AI 项目日报 #36 — jnMetaCode/agency-agents-zh：把 266 个"中国本土化"AI 专家塞进任意编码工具

## 一、项目速览

**jnMetaCode/agency-agents-zh** 是一款"即插即用"的中文 AI 专家角色库，将 266 个高度专业化的人设（覆盖工程、设计、营销、金融、法律、供应链、游戏、空间计算等 **18 个部门**）封装成 Markdown 文件，通过 `scripts/convert.sh` + `scripts/install.sh` 两阶段流水线，自动转换为 `.mdc`（Cursor）、`agents/`（Claude Code）、`CONVENTIONS.md`（Aider）等 17 款主流 AI 编程工具的本地格式。

它不是另一个 Awesome-List 式的"提示词合集"，而是一套**角色即代码（Role-as-Code）** 工程：每个智能体都带有 YAML frontmatter（身份元数据）+ 结构化正文（使命 / 工作流程 / 关键红线 / 交付物清单），并由 NEXUS 编排框架按 7 阶段生命周期调度。配合官方 `agency-orchestrator` 编排器，一句话即可让多位专家按 DAG 协作。

## 二、项目背景

在 2025–2026 年大模型 Agent 浪潮中，"提示词"逐渐演化为"可被工程化调度的角色资产"。GitHub 上英文圈最火的项目是 [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents)，但其角色全部围绕北美 SaaS 场景：CRM、SEO、SaaS 增长、Stripe 集成……**对中国开发者来说，"小红书种草"、"抖音电商"、"飞书机器人"、"政务 ToG 投标准备"、"医疗合规审查"等高频场景完全缺失**。

`agency-agents-zh` 正是为填补这一空缺而诞生的中文社区版。它做的事情有三件：

1. **完整翻译上游 215 个英文角色**（保留原文专业度，附中文 SOP）；
2. **原创 50 个中国市场专属角色**（小红书 / 抖音 / 微信 / B 站 / 飞书 / 钉钉 / 跨境电商 / 政务 ToG / 医疗合规 / Qt 工业上位机 / 高考志愿填报 / 留学规划等）；
3. **构建 NEXUS 多智能体编排框架**，把"专家库 + 工具链 + 生命周期管理"打包成一个可持续演进的开源生态。

## 三、核心功能

1. **266 个即插即用专家人设** —— 每个角色都带"身份 + 工作流 + 交付物 + 红线"四件套，远超"你是一个 X 专家"的浅层提示词
2. **17 种 AI 工具一键安装** —— 通过 `install.sh --tool <name>` 自动检测本地已安装的 IDE / CLI（Claude Code、Cursor、Copilot、Trae、Windsurf、Aider、Codex、Qwen Code、WorkBuddy、Hermes Agent、DeerFlow 2.0 等），把角色部署到对应配置目录
3. **NEXUS 7 阶段生命周期编排** —— Discovery → Strategy → Foundation → Build → Hardening → Launch → Operate，配合 "Evidence Over Words" 质量门禁，不达标不能进入下一阶段
4. **三种激活模式自适应** —— `NEXUS-Full`（190+ 智能体，12-24 周企业级）/ `NEXUS-Sprint`（15-25 个，2-6 周 MVP）/ `NEXUS-Micro`（5-10 个，1-5 天单任务）
5. **scenario runbook 场景剧本** —— 内置创业 MVP、企业级 Feature、营销 Campaign、Incident Response 4 套标准化剧本
6. **Agency Orchestrator 引擎** —— 配套的 npm 包 `agency-orchestrator`，支持 `ao compose "<任务>" --run` 一句话调度多 Agent
7. **在线专家库** —— [ao.aiolaola.com/experts](https://ao.aiolaola.com/experts) 提供搜索 / 筛选 / 复制 216 位专家完整提示词

## 四、技术亮点

- **Role-as-Code 工程化**：每个 `.md` 文件有严格 YAML frontmatter（name / department / role / tools 等字段），由 `scripts/lint-agents.sh` 自动校验字段完整性，从源头杜绝"半成品 prompt"
- **两层流水线架构**：`convert.sh` 解析 Markdown → AST → 工具专属格式（`.mdc` / `.json` / `CONVENTIONS.md`），`install.sh` 检测本地环境（`~/.claude/agents/`、`.cursor/rules/` 等）→ 智能复制到目标目录
- **NEXUS 编排协议**：通过 "Pipeline Integrity" 原则保证阶段间不丢失上下文；Dev-QA Evidence Loop 让工程类智能体与 reality-checker 配对运行，避免"看起来对但实际坏掉"的交付
- **OpenClaw 优先适配**：将每个角色拆为 SOUL.md（人设）+ AGENTS.md（业务能力）+ IDENTITY.md（简介）三件套，与 OpenClaw 的子代理调度深度协同
- **OpenCC 自动繁简转换**：`scripts/sync-tw.sh` 同步生成繁體中文版（README.zh-TW.md），覆盖港澳台市场
- **质量门禁制度**：每个 Phase 都有可量化的"通过条件"（测试通过率、代码覆盖率、设计走查截图），严格践行 "Evidence Over Words" 原则
- **赞助商生态闭环**：APINEBULA（银河录像局旗下企业级 AI 聚合平台）+ 优云智算（UCloud 旗下 AI 云平台）双重赞助，确保 API 调用 + GPU 算力可一键对接

## 五、适用人群

- **国内 ToB / ToG 团队**：需要快速搭建"小红书运营 + 抖音投放 + 飞书集成 + 合规审查"组合工作流

- **高校学生 / 应试家庭**：内置"高考志愿填报顾问"、"留学规划顾问"角色，2026 年高考季刚需
- **内容创作者 / 跨境电商**：需要持续输出小红书笔记 / 短视频脚本 / TikTok 投流策略
- **多 Agent 研究者**：相比 LangGraph / AutoGen / CrewAI，NEXUS 提供更轻量的中文生态方案

## 六、快速上手

```bash
# 1. 安装 npm 包
npm install -g agency-agents-zh

# 2. 克隆仓库（获取安装脚本）
git clone --depth 1 https://github.com/jnMetaCode/agency-agents-zh.git
cd agency-agents-zh

# 3. 选择目标工具并安装（推荐 OpenClaw）
./scripts/convert.sh --tool openclaw
./scripts/install.sh --tool openclaw

# 4. 重启 OpenClaw 网关
openclaw gateway restart

# 5. 一句话调用专家
# 在 OpenClaw 中说：
# "启动 marketing-xiaohongshu-operator 帮我写防晒霜种草文案"
```

其他工具安装（Claude Code / Cursor / Copilot / WorkBuddy 等）只需把 `--tool openclaw` 改为对应名称即可。

## 九、结语

`agency-agents-zh` 不只是一个角色库，它代表了 AI 工具链向"角色即资产"演进的重要一步。当 LangChain / LlamaIndex 还在卷底层框架时，中文社区已经从"提示词模板"升级到"角色市场 + 编排协议 + 多工具适配"的完整生态。

1. 先用 NEXUS-Micro 模式试 1-2 个角色（小红书运营 + 前端开发者），体验效果；
