项目概览：manaflow-ai / cmux

macOS 独占 Swift GPL 2026-01-28

cmux 是一个专为 AI 编码代理设计的原生 macOS 终端应用，基于 Ghostty 的底层渲染库 libghostty 构建。 它将传统"终端标签页"升级为带 Agent 状态感知的工作区指挥中心：垂直标签显示 Git 分支、PR 状态、端口和最新通知； Agent 需要关注时，对应窗格会亮起蓝色光环并推送 macOS 通知。 Ghostty 创始人 Mitchell Hashimoto 公开称赞它是为 "terminal-based agentic workflows" 而生的创新项目。

核心功能

1. 垂直标签工作区

左侧边栏不仅列出会话，还直接显示每个工作区的 Git 分支、关联 PR 状态/编号、工作目录、监听端口和最新通知文本，让多任务状态一目了然。

2. Agent 通知环系统

Agent 完成任务或等待确认时，窗格显示蓝色光环、侧边栏标签高亮、弹出通知面板并触发 macOS 桌面通知。支持 CLI、OSC 777 和 OSC 9/99 三种触发方式。

3. 内置可编程浏览器

基于 WKWebView 的浏览器窗格支持 DOM 快照、点击、填表、执行 JS、读取控制台和网络活动。Agent 可直接验证网页改动，SSH 远程工作区中 localhost 也能透明路由。

4. Claude Code Teams 原生支持

运行 cmux claude-teams，每个 teammate 自动渲染为原生分屏，拥有独立侧边栏元数据和通知状态，无需 tmux 配置。

5. CLI + Unix Socket API

外部脚本可通过 cmux CLI 或 Unix socket 创建工作区、分屏、发送按键、读取屏幕、控制浏览器、设置状态栏，实现完整自动化编排。

6. 原生 Swift + AppKit

非 Electron/Tauri，启动快、内存占用低、GPU 渲染流畅。自动读取 ~/.config/ghostty/config，主题字体颜色无缝迁移。

技术亮点

libghostty 作为"终端界的 WebKit"

cmux 不是 Ghostty 的分支，而是把 libghostty 嵌入 Swift/AppKit 外壳中，既获得 Ghostty 的 GPU 加速渲染能力，又拥有原生 macOS GUI 的完整能力。

基于标准 OSC 序列的 Agent 通知捕获

监听标准终端转义序列 OSC 9/99/777，任何能向 stdout 输出的 Agent 或脚本都能触发通知，实现真正的 Agent 无关设计。

SwiftUI + AppKit 混合架构

根据 DeepWiki 代码解析，项目采用分层架构：cmuxApp 作为入口，TabManager 管理全局状态，BonsplitController 负责复杂分屏，TerminalController 监听 Unix socket 供外部调用。

亮点总结：cmux 的聪明之处在于不重复造轮子——用 Ghostty 解决渲染性能，用原生 macOS 框架解决交互体验，用标准 OSC 协议解决 Agent 集成，三者组合成一个为 AI 编码时代重新设计的终端。

快速上手

# Homebrew 安装
brew tap manaflow-ai/cmux
brew install --cask cmux

# 配置 CLI
sudo ln -sf "/Applications/cmux.app/Contents/Resources/bin/cmux" /usr/local/bin/cmux

# 验证
cmux list-workspaces
cmux notify --title "Hello" --body "cmux CLI is working"

# 安装 Agent hooks（可选）
cmux hooks setup

系统要求：macOS 14.0+，Apple Silicon 或 Intel。首次启动时点击"打开"以绕过 Gatekeeper 提示。

适用人群

  • 多 Agent 并行开发者：同时跑 Claude Code、Codex、Aider 等，需要视觉化状态监控
  • macOS 原生性能党：厌倦 Electron 终端的卡顿和高内存占用
  • 全栈/前端开发者：需要终端和浏览器并排、Agent 自动验证网页改动
  • 工具链/自动化工程师：想基于 Socket API 构建自定义 Agent 工作流
  • 追求开箱即用的团队：不想写大量 tmux 配置，希望 GUI 即开即用

局限与风险

  1. macOS 独占：Windows/Linux 用户无法使用
  2. 会话恢复≠进程恢复：恢复布局，但运行中的 Agent 进程不会自动复活
  3. GPL 许可：商业嵌入需联系 Manaflow 获取授权
  4. 生态较年轻：插件和周边生态不如 iTerm2/tmux 成熟
