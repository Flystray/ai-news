🚀 今日推荐：everything-claude-code (ECC)

affaan-m/everything-claude-code 是 GitHub 上最热门的 AI Agent Harness 性能优化系统，斩获 Anthropic 黑客松冠军。由 affaan-m 单人 10 个月高强度迭代打磨，已突破 22.5 万 star / 3.4 万 fork / 230+ 贡献者。

2026 年 6 月发布的 v2.0.0 正式重命名为"agent harness 操作系统"，从"Claude Code 配置包"进化为支持 13+ AI 编程工具（Claude Code、Codex、Cursor、OpenCode、Gemini CLI、Zed、Kiro、Qwen、Trae、CodeBuddy、VS Code、Antigravity、GitHub Copilot）的跨平台工程化框架。

🎯 一句话定位：原生 Claude Code 是"聪明但无约束的实习生"，ECC 为其配备完整的规划师、架构师、测试专家、安全审计员、构建修复师，让 AI 开发从"自由发挥"走向"标准化工程化"。

🎯 核心功能

1. 64+ 专业子代理（Agents）

覆盖规划（planner）、架构（architect）、TDD 指导、代码审查、安全扫描、构建错误修复、E2E 测试、死代码清理、文档同步、Go/Python/TypeScript 语言专项审查等全流程角色，每个代理绑定特定工具权限与模型（Haiku/Sonnet/Opus）。

2. 261+ 领域技能（Skills）

12 种编程语言（TypeScript、Python、Go、Java、Kotlin、C++、Rust、PHP、Perl、Shell、Swift、Markdown）最佳实践合集；框架级 Skills 覆盖 NestJS、Django、Laravel、SpringBoot、React、Next.js；MCP 相关 18 个专项技能。

3. 68+ 斜杠命令（Commands）

提供 /plan、/tdd、/code-review、/security-audit、/e2e-test、/build-fix、/refactor-clean、/learn、/checkpoint、/verify 等一键工作流入口。

4. 8 类 Hook 事件

PreToolUse、PostToolUse、SessionStart、SessionEnd、Stop、PreCompact 等生命周期钩子，覆盖质量门禁、记忆加载/保存、会话摘要提取、后台进程管理。

5. AgentShield 安全审计系统

命令净化（拦截 rm -rf /、SSH 配置修改等危险操作）、CVE 数据库实时扫描、敏感数据边界控制（拒绝访问 ~/.ssh/、~/.aws/credentials）、102 条安全规则 + 1282 个测试用例的"红蓝对抗"防护。

6. 跨会话记忆与持续学习（Instinct 系统）

SessionStart 自动加载历史上下文，SessionEnd 提取新模式为可重用 Skill；Instinct 系统带置信度评分，行为越用越适配；SQLite 状态存储 + CLI 查询工具。

7. 并行编排（Git Worktree + 子代理）

通过 git worktree add 拆分大型重构为多个独立工作树并行处理；iterative-retrieval 模式解决子代理上下文稀释问题（仅传递最相关的 top-5 上下文片段，最大 2000 token）。

8. 跨平台适配（13+ Harness）

原生支持 Claude Code、Codex、Cursor、OpenCode、Gemini CLI、Zed、Kiro、Qwen、Trae、CodeBuddy、VS Code、Antigravity、GitHub Copilot；通过 install-modules.json 清单驱动选择性安装。

💡 技术亮点

1. 六层架构设计

从入口（.claude-plugin/plugin.json）→ 子代理层（agents/*.md）→ 工作流层（skills/）→ 命令层（commands/）→ 规则层（rules/）→ 钩子层（hooks/hooks.json）分层解耦；每一层都有独立 schema 校验。

2. Manifest-driven 安装管线

install-modules.json 映射组件到不同 harness 目标（claude/cursor/opencode/codex），避免配置冲突；用户可按需勾选组件安装。

3. 包管理器自动检测级联

优先级：环境变量 CLAUDE_PACKAGE_MANAGER → 项目 .claude/package-manager.json → package.json 的 packageManager 字段 → 锁文件检测 → 全局配置 → 回退默认。

4. Rust 控制平面原型（ECC 2.0 alpha）

ecc2/ 目录用 Rust 重写控制面，已实现 dashboard、start、sessions、status、stop、resume、daemon 子命令；状态不可变快照设计，每次关键操作后打快照支持回滚。

5. 双层技术栈

JavaScript 3.94M（外壳/插件层）+ Rust 1.82M（内核/控制面）+ Python 331K（Dashboard + 辅助）+ Shell 190K（安装器）；Rust 占比 22%，标志着向原生二进制迁移的长期路线。

6. Hermes operator 集成（v2.0）

与 Hermes Agent 互补——Hermes 学"用户在做什么"（运营/市场场景），ECC 学"代码应该怎么写"（工程化场景）；Instinct 系统（带置信度）vs Memory 系统（叙事性）的差异化定位。

7. 研究优先（Research-First）方法论

配套三套完整指南——精简指南（30 分钟入门）、详细指南（Token 预算/记忆系统/评估框架/并行化原理）、安全指南（攻击向量/沙箱技术/CVE 防护）。

⚡ 快速上手

1. 通过插件市场安装（推荐，30 秒）

# 添加市场源
/plugin marketplace add affaan-m/everything-claude-code

# 安装插件
/plugin install everything-claude-code@everything-claude-code

# 重启 Claude Code

2. 手动克隆（用于自定义修改）

git clone https://github.com/affaan-m/everything-claude-code.git
mkdir -p ~/.claude/rules/
cp -r everything-claude-code/rules/* ~/.claude/rules/

3. 典型工作流（以 Todo 后端为例）

  1. 用户说："开发一个 Todo 后端 API，支持增删改查"
  2. /plan → Planner 拆解为用户/商品/订单/支付模块
  3. Architect 设计 RESTful API + 数据库表结构
  4. TDD Guide 编写测试（RED 阶段）
  5. Code Agent 生成业务代码（GREEN 阶段）
  6. Code Reviewer 审查可读性与性能
  7. Security Reviewer 扫描 SQL 注入/XSS
  8. Build Error Resolver 修复依赖冲突
  9. E2E Runner 执行 Playwright 全链路验证
  10. Doc Updater 生成 API 文档

全程无需人工干预，自动交付可部署的完整后端系统。

性能数据（社区报告）

  • Token 消耗：通过任务分级模型选择 + 系统提示精简，平均节省 30-50% Token
  • 代码质量：强制 TDD + 80% 测试覆盖率，bug 率显著降低
  • 开发速度：复杂任务自动拆解 + 并行处理，单人产出接近小型团队

⚠️ 风险与局限

  • 单维护者风险：项目高度依赖 affaan-m 一人，bus factor 为 1；社区正在迁移部分组件到独立组织
  • 入门曲线陡峭：261 个 Skills + 64 个 Agents 对新手过载，建议从"精简指南"入手
  • 配置冲突：跨 Harness 适配时可能出现 rules 冲突，需要 manifest-driven 选择性安装
  • 依赖 Node.js：Hook 脚本用 Node.js 实现，Windows 环境需注意 PATH 配置
  • 企业版付费：核心功能 MIT 免费，但 Pro 版（$19/座位/月）提供仪表盘 + 高级安全审计
