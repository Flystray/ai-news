🚀 今日推荐：LeanCTX

yvgude/lean-ctx 是一个 AI Agent 的上下文智能层（Context Intelligence Layer）——一个本地 Rust 二进制，插在 Agent 和你的代码/Shell/数据之间，负责决定 Agent 读什么、压缩 Agent 发什么、记住 Agent 学过什么、保护 Agent 碰什么。官方实测数据：60-90% 的 Token 削减，冷启动场景最高可达 99%。

一条 lean-ctx setup 即可自动检测并集成 Claude Code、Cursor、Windsurf、Copilot 等 30+ AI Agent，77+ MCP 工具开箱即用。

🎯 一句话定位：不是 Prompt 模板，不是向量数据库——是运行在 Agent 和文件系统之间的"上下文操作系统"，用 tree-sitter AST 提取代码骨骼、Thompson Sampling 自适应压缩、艾宾浩斯遗忘曲线管理记忆，一个二进制搞定 Token 膨胀。

🔧 核心功能

1. 四层压缩引擎（Terse Engine）

从原始文件到送入模型的上下文块，经过 4 层流水线提纯：

  • 第 1 层 · 确定性过滤：剥离 badge、空行、注释、重复分隔符
  • 第 2 层 · AST 骨骼提取：tree-sitter 解析 18 种语言语法树，只保留类签名/方法签名/类型定义
  • 第 3 层 · 自适应密度：语义路由器根据上下文动态选择 10 种读取模式（map/signatures/entropy 等）
  • 第 4 层 · Agent 成型：按目标 Agent 特性（Claude 偏 JSON、Cursor 偏代码块）重新格式化

最巧妙的是语义路由器内置 Thompson Sampling 多臂赌博机，根据历史压缩效果自动学习最优压缩阈值——系统越用越聪明。

2. 上下文连续性协议（CCP）

解决 AI Agent 的"会话失忆"问题：

  • 跨会话记忆：自动持久化任务（Tasks）、发现（Findings）、决策（Decisions）
  • 冷启动优化：新会话从 CCP 索引恢复关键上下文，Token 降低 99%
  • 属性图：维护代码实体关系（调用链/依赖/继承），ctx_graph 一次性获取

3. Token Dense Dialect（TDD）

用数学符号速记法压缩代码签名：λ 替代 function、§ 替代 section、τ 替代 type。在压缩基础上再省 8-25% Token，LLM 对数学符号有天然语义理解。

4. Cognition v2：仿人类认知召回

  • 艾宾浩斯遗忘曲线：上下文条目保留概率随时间衰减，被"命中"后增强稳定性
  • 赫布 Eviction：经常一起访问的条目形成"关联簇"，超限时优先驱逐孤立条目

让 Agent 的上下文管理从"先进先出"进化到"像人一样记住重要的、忘记无关的"。

6. Shell Hook：95+ CLI 工具透明压缩

自动拦截 git、docker、cargo、npm 等 95+ 命令行工具的输出并压缩。git status 从 ~800 tokens → ~120 tokens，重复读文件从 ~2000 tokens → ~13 tokens（SessionCache 命中时）。

7. 安全护栏：从路径监狱到 Lean4 形式化验证

  • 路径监狱（Path Jail）：文件访问限制在白名单目录内
  • 密钥防御：自动检测并脱敏 .env、API Key
  • Lean4 形式化验证：核心安全属性通过定理证明器验证——开源 AI 工具中极为罕见

💡 技术亮点

单 Rust 二进制，本地优先

整个系统编译成一个二进制文件，无需 Node.js/Python 运行时，无需外部服务。所有压缩、缓存、记忆在本地完成，代码不离开机器。

SessionCache：13 Token 重新读取

Agent 第二次读同一文件时，直接从 SessionCache 返回极简指纹——约 13 tokens（相比首次 ~2000 tokens）。缓存键基于路径 + 内容哈希，文件修改后自动失效。

实时仪表盘 + Token 预算控制

可视化每个 Agent 会话的 Token 消耗分布：哪些文件最贵、哪些工具调用最频繁、压缩率多少。支持设定 Token 预算上限，超限时自动降级压缩级别。

可配置的认知模型

[cognition]
forgetting_model = "ebbinghaus"  # 或 "linear"
base_stability_days = 7

[security]
mode = "enforce"  # enforce / warn / off

🚀 快速上手

# 1. 安装
npm install -g lean-ctx-bin

# 2. 一键集成（自动检测已安装的 AI Agent）
lean-ctx setup

# 3. 或指定特定 Agent
lean-ctx init --agent claude-code
lean-ctx init --agent cursor
lean-ctx init --agent gemini-cli

# 4. 启动 MCP Server
lean-ctx mcp serve

# 5. 查看实时仪表盘
lean-ctx dashboard

手动集成 Claude Code 的 MCP 配置：

{
  "mcpServers": {
    "lean-ctx": {
      "command": "lean-ctx",
      "args": ["mcp", "serve"]
    }
  }
}
