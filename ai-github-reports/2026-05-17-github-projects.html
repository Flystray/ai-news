Context Mode 是一个 MCP Server，专门解决 AI 编程助手的上下文窗口污染问题。通过沙箱隔离+SQLite+FTS5+输出压缩四合一方案，将工具输出减少 98%（315 KB → 5.4 KB），会话时长从 30 分钟延长至 3 小时。

📌 项目背景

AI 编程助手处理复杂项目时，工具输出正在悄悄填满上下文窗口。实测数据：1 次 Playwright 快照占 56 KB（14K tokens），20 条 GitHub Issues 占 59 KB。工作 30 分钟后，40% 的上下文已被工具输出污染。Agent 压缩对话时会遗忘工作状态——正在编辑的文件、任务进度、已解决的问题。

🚀 核心功能

  • Context Saving（98% 压缩率）：沙箱隔离拦截原始数据，仅 stdout 摘要入 context。Playwright 快照 56 KB → 299 B，节省 99.5%
  • Session Continuity（会话连续性）：事件持久化到 SQLite，压缩后通过 FTS5 BM25 搜索只取相关事件片段，Agent 从中断处继续
  • Think in Code（脚本优先范式）：从"47 × Read() 调用 = 700 KB"变为"1 × ctx_execute() = 3.6 KB"，节省 100 倍
  • Output Compression（输出压缩）：去除填充词和客套话，模型输出减少 65-75%
  • Knowledge Base（智能知识库）：FTS5 + BM25 搜索，8 级渐进回退（Porter AND → 模糊纠正），Smart Snippets 语义窗口提取
  • 11 个 MCP 工具：ctx_execute、ctx_batch_execute、ctx_execute_file、ctx_index、ctx_search、ctx_fetch_and_index 等

⚙️ 技术亮点

  • 三层过滤叠加架构：进程隔离（~50%）+ 智能截断（~30%）+ 意图驱动索引（~18%）= 98.3% 总压缩率
  • FTS5 + BM25 8 级回退策略：Porter 词干 AND → OR → Trigram 子串 → Levenshtein 模糊纠正，精确检索语义窗口
  • 15 个平台 Hook 适配器：Claude Code（4/4 hooks）、Gemini CLI、VS Code Copilot（4/4）、Cursor（2/4）等，非侵入式工具调用拦截
