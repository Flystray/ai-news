项目背景：Agent 学习资源的碎片化困境

AI Agent 学习资源的通病是不成体系：今天一篇 RAG 教程、明天一篇 MCP 介绍、后天一篇多 Agent 科普，合在一起是一盘散沙。厂商文档口径也不一致：OpenAI 讲 function calling，Anthropic 讲 tool use，Google 讲 grounding。

这本书用一个公式把碎片焊在一起：Agent = LLM + 上下文 + 工具。LLM 是大脑（推理），上下文是感知（看到什么、记得什么），工具是双手（能做什么）。Harness、Context Engineering、Agent Skills、Computer Use、评估驱动开发——半年来爆火的概念都能在这套结构里找到位置。

🎙️ 耐人寻味的细节：作者坦承本书大部分创作没有依赖传统打字——先向语音 Agent 口述提纲，让 Agent 调研、整理初稿，再持续讨论修改。一本讲 Agent 的书，本身就是 Agent 深度参与完成的作品。

核心功能

1. 十章正文：从基础到生产的完整进阶路线

第 1 章 ReAct 循环 → 第 2 章上下文工程（KV Cache、Agent Skills、压缩）→ 第 3 章记忆与 RAG → 第 4 章工具与 MCP → 第 5 章 Coding Agent（含 OpenClaw 参考实现）→ 第 6 章评估（ELO、沙箱）→ 第 7 章后训练（SFT/RLVR/VLA）→ 第 8 章自我进化 → 第 9 章多模态与 Computer Use → 第 10 章多 Agent 协作。

2. 93 个配套实验：不是讲概念，是跑代码

每章 4~16 个独立 Python 项目，70+ 个配好 API Key 即可运行，按 ✅ 可运行 / 📖 复现 / 🚧 设计三级标注。从零训 LLM（MiniMind）、提示注入攻防（3 攻击 × 4 防御 = 12 组对照实验）、SWE-bench/OSWorld/GAIA 复现，甚至 SO-100 机械臂 Sim2Real 抓取。

3. 对照实验驱动：用数据说话，不站队

记忆系统 mem0 vs Memobase 各实现一版；检索做稠密/稀疏/混合三版对比；讲多 Agent 时直言"大多数场景多 Agent 并不比单 Agent 好，只是徒增复杂度"——这种诚实在 AI 领域相当稀缺。

4. 不依赖框架：直接调 LLM API

所有实验直接调 LLM API 实现核心逻辑，不绑定 LangChain 等重型框架，学习者能看清 ReAct 循环、工具调用、记忆管理的底层实现。

5. 出版管线本身就是工程范本

Pandoc + XeLaTeX + ElegantBook 生成专业 PDF；自定义 Lua 过滤器处理实验框与交叉引用；配图用 Python 脚本程序化生成 SVG；GitHub Actions 每次推送自动重建在线版。一本书被当成软件产品持续交付。

6. 九种语言社区翻译

英/日/俄/阿拉伯/越南/泰米尔/土耳其/正体中文 8 种社区翻译，在线阅读站支持多语言切换、全文搜索、实验直达。

技术亮点

1. "Harness 工程"命题：模型之外才是竞争力

全书核心工程主张："Model-as-an-Agent" 在生产环境远远不够。真正决定 Agent 可靠性的是模型外围的"马具"——约束、验证、记忆、沙箱、回滚。这直接回答了"为什么同样的模型，Claude Code 比裸调 API 好用得多"。

2. 概念到代码的双向映射

公式严格映射到代码：LLM → 第 6/7 章（评估与后训练），上下文 → 第 2/3 章，工具 → 第 4/5 章。book/ 是正文源码，chapter1-10/ 是可执行项目，cursor-chats/ 甚至公开了用 Cursor 辅助开发本仓库的完整对话日志。

3. 论文级可复现基建

第 6/7/9/10 章的 19 个外部仓库（SWE-bench、OSWorld、GAIA、verl、MiniMind、browser-use、斯坦福 AI 小镇等）提供一键克隆脚本并标注特定 commit，保证复现一致性。

写在最后

两点启发：

1. "开源一切"依然是最强的传播策略。正文、PDF、配图、代码、甚至写书的 Cursor 对话日志全部公开——结果是 10 个月 24.5K Star、9 种语言社区翻译。知识产品的护城河不是封闭，而是持续迭代的速度。

2. "Agent = LLM + 上下文 + 工具"的价值被低估了。它不仅是教学框架，更是工程决策框架：系统出问题时可以立刻定位是模型能力不足（换模型/后训练）、上下文缺失（改记忆/检索），还是工具设计不当（改 ACI）。在概念满天飞的 Agent 领域，一个能落地的思维模型比十个新名词都值钱。
