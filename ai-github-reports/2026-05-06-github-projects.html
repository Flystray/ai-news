📌 项目背景

你有没有过这种经历——明明昨天看过一个重要信息，翻遍浏览器历史也找不到，只能干着急？或者开会时来不及记笔记，回头想整理行动项却一片空白？

这类问题催生了"桌面 AI 记忆"这个赛道。Rewind.ai 是最早的探索者，但它后来转向了云端付费产品并最终停止维护。screenpipe 接过了这面旗帜，用完全开源、本地优先的方式重新定义了"个人 AI 记忆"——它的核心理念是：你的电脑应该比你更清楚你做过什么。

screenpipe 由 Rust 语言构建（强调性能与安全），于 2024 年 6 月发布，至今已获得 18.5k GitHub stars 和 1.7k forks，项目保持高度活跃。与传统录屏工具不同，screenpipe 的价值不在于"录像"，而在于让 AI 真正理解屏幕上的内容并采取行动。

🛠️ 技术栈

Rust Tauri TypeScript SQLite MCP (Model Context Protocol) Ollama Claude / GPT / Gemini

架构亮点：Rust 语言全栈本地化架构，CPU 占用仅 5-10%、内存 0.5-3GB、每月约 20GB 存储。采用"事件驱动录制"策略，只在检测到有意义的变化（切换应用、鼠标点击、键盘输入、滚动）时保存截图，大幅节省存储。

🤖 Pipes 自动化系统

Pipes 是 screenpipe 最具创新性的功能——以 Markdown 文件定义的定时 AI Agent 工作流。每个 pipe.md 包含 prompt 和触发条件，screenpipe 自动运行 AI 编码 Agent 查询屏幕历史并执行动作。

📝 自动会议纪要
💡 Idea 追踪
📓 Obsidian 同步
🔔 定时提醒
🔄 Linear 自动更新
📧 Gmail 摘要
📊 每日工作回顾
🔍 上下文感知搜索

触发条件支持：定时触发（每天早上 9 点）、事件触发（会议结束时）、应用触发（打开某个 App 时）。社区已共享大量预构建 pipes。

✨ 核心功能（6 大能力）

🖥️ 24/7 全天候录制

后台持续记录屏幕画面和麦克风音频，采用事件驱动策略——只在有意义的操作时保存，而非每秒机械录制，存储效率更高

🔍 自然语言 AI 搜索

问 AI"过去 5 分钟我在看什么？""这周我和谁讨论过定价？"，超越关键词搜索，AI 理解屏幕内容的语义

🔌 MCP 协议集成

将搜索 API 暴露为 MCP 服务器，Claude Desktop、Cursor、Cline、Continue 等 AI 编码助手可直接查询你的屏幕历史

🤝 48 个应用深度集成

覆盖 Linear、Jira、Notion、Slack、GitHub、Figma、Stripe 等主流工具，Pipes 自动化可自动调用这些集成

🗣️ 中文 OCR + 会议转录

内置多语言 OCR 引擎（支持中文），音频转录识别讲话者，自动生成会议纪要（要点 + 每人行动项 + 决议）

🔒 三层隐私保护

100% 本地处理、支持 Ollama 完全离线、端到端加密存储、自动过滤密码和 PII，数据永远不会离开你的设备

💡 技术亮点（4 大架构创新）

亮点 1：Rust 全栈本地架构

全链路 Rust 构建，CPU 占用仅 5-10%，内存 0.5-3GB，每月约 20GB 存储。所有数据从捕获到处理到存储全部本地完成，无任何数据上传。

亮点 2：三层 AI 集成架构

MCP 服务器层（供外部 AI 助手调用）、Chat UI 层（多模型切换：Claude Opus 4.7、Gemma 4 Confidential、Qwen 3.5）、Pipes Agent 层（后台自动化）。三层架构覆盖所有场景需求。

亮点 3：Ollama 完全离线支持

接入 Ollama 后可完全在本地运行 Llama、Qwen 等开源大模型，实现零云依赖的 AI 记忆体验。对于注重隐私的用户，这是 Rewind.ai 和微软 Recall 无法提供的核心优势。

亮点 4：智能隐私过滤器

按窗口、按应用、按 Chrome 扩展过滤录制内容；自动过滤密码输入框和 PII 信息；可选端到端加密存储。三种录制模式（会议模式 / 编程模式 / 休息模式）灵活切换。

💰 关于费用

免费 + MIT 开源

screenpipe 本身完全免费（MIT 开源协议）。桌面 App 为一次性购买，包含所有功能并自动更新。

MCP 查询免费配额：匿名用户每日 25 次，注册用户 50 次，Pro 用户 200 次。超出部分 $0.10/次。使用本地 Ollama 则完全不受此限制。

👥 适用人群

  • 独立开发者 / 程序员：在 Cursor 或 Claude Desktop 中直接搜索自己写过哪些代码、和同事讨论过哪些技术方案，大幅提升代码复用率
  • 远程团队成员 / 频繁开会者：会议结束后自动生成结构化纪要和行动项，自动同步到 Linear、Jira
  • 知识工作者 / 研究者：回顾"两周前在哪个网站看过这篇论文"，自然语言搜索比任何浏览器历史都高效
  • 注重隐私的用户：所有数据本地存储，支持 Ollama 完全离线，Rewind.ai / 微软 Recall 的真正开源替代
