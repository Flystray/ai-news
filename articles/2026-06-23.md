## 项目背景

AI Agent 正在成为开发者的标配工具，但一个核心矛盾日益尖锐：**预算有限，但要求不低**。OpenClaw 用固定配置跑强模型，简单问候也按推理 Token 计费；Hermes Agent 靠关键词+字数粗糙判断难度，只有一条省钱链路；主流 Agent 框架要么用强模型全程"专车接送"，要么把省钱逻辑硬编码进配置文件——Agent 的「成本效率」和「智能质量」始终被当作零和博弈。

**OpenSquilla** 提出了一个不同的解法：**同样的预算，更高的智能密度**。它用微内核架构把 Agent 运行时拆成 5 层——编排器极简（百行级），所有能力以插件接入，出错自动跳过+回滚。核心创新在于 **SquillaRouter**：LightGBM 分类器实时判断 prompt 难度，简单问题坐公交（GPT-4o-mini），复杂问题才叫专车（Claude 3.5 Sonnet），再加上四层认知记忆、MetaSkills 自进化协议、系统调用级安全沙箱——Agent 不只是省钱，而是每一分钱都花在刀刃上。

项目 2026 年 5 月创建，3 周内星数从 1,000 涨到 3,000+，Apache-2.0 开源，有完整中文支持（opensquilla.ai/zh/）。

## 核心功能

### 1. SquillaRouter 智能路由：ML 分类器实时选模型
不是关键词匹配或字数统计，而是真正的机器学习路由。LightGBM + ONNX 双模型推理管道分析 prompt 的语义和结构特征，分为四级：
- **c0（极简）**：问候、停止命令等 → 最廉价模型（R0）
- **c1（低难度）**：信息检索、格式化、单轮问答 → flash 模型（R1）
- **c2（中等）**：多步推理、标准编码、复杂摘要 → 平衡模型（R2）
- **c3（高难度）**：深度推理、复杂逻辑、需要 Thinking 模型 → 强推理模型（R3）

混合特征分析：手工特征（长度、语言、代码片段、关键词）+ 嵌入语义特征多维度判断。还有情绪升级机制——用户消息包含"wrong""incorrect""redo"等抱怨词时，自动升级 tier 确保高质量修正。思维深度分级：简单问题关闭推理计费，复杂问题才开启深度思考，避免为"你好"付推理 Token 的钱。自适应 Prompt：根据难度自动调整提示词深度，简单问题轻装上阵，复杂问题全力以赴。官方数据：**60-80% Token 成本节省**。

### 2. 四层认知记忆：类人脑分层运作
不是简单的向量数据库，而是认知科学启发的分层架构：
- **Working Memory**（工作记忆）：TurnContext 中的即时对话状态，高挥发
- **Episodic Memory**（情节记忆）：SQLite SessionStorage 存储过去交互的时序历史和因果链
- **Semantic Memory**（语义记忆）：sqlite-vec 向量索引的事实、实体和归纳知识，FTS5 关键词兜底
- **Raw Memory**（原始记忆）：MEMORY.md 人类可读 Markdown，Agent 知识的"事实之源"

热门记忆"冒泡"晋升——经常被召回的自动浮顶，越常用越好找；冷门记忆自然沉底。时间衰减机制——带时间标签的记忆按指数衰减自动淡化，标记为"永久"的核心知识不受影响。混合检索：向量语义 + 全文关键词双管齐下，向量分数低于阈值时自动 FTS5 兜底，既懂"意思相近"也能精确匹配。本地 ONNX BGE 嵌入推理，CPU 即可运行，数据不出本机。

### 3. Dream 整合：每 24 小时让 AI"做梦"
借鉴认知科学的睡眠巩固理论，OpenSquilla 实现了 **Memory Dream**——后台周期性整理过程：
- **Phase 1**：LLM 分析近期交互 transcript，提取"常青"事实
- **Phase 2**：子 Agent 精确编辑 MEMORY.md，写入持久知识

每 24 小时自动执行，把零散情节归纳整理进语义层，就像睡眠中巩固记忆一样——Agent 用得越久越懂你。

### 4. MetaSkills 协议：Agent 自己给自己长能力
不是静态 skill 列表，而是元协议——告诉 Agent 如何检索、筛选、组合，乃至自主进化：
- **自组织工作流**：多步骤变成可复用、可审视的工作流，组合解析+步骤调度+提案门控
- **meta-skill-creator**：内置 MetaSkill，把反复出现的多 Skill 协作模式凝练成新 MetaSkill 提案——Agent 用它给自己长出新能力
- **N+ 社区 Skills**：Agent 自主检索、排序并调用社区贡献的 Skills，遇到新任务不需人工挑选
- **10+ 内置 MetaSkills**：研究到报告、论文草拟、求职准备、项目规划、短剧制作等，装好就能跑
- **梦境模式**：用户空闲时回看执行痕迹，提炼使用习惯，自动起草新 MetaSkill 候选——能力在后台悄悄生长

### 5. 安全沙箱：系统调用级隔离
不依赖 Docker，而是用操作系统原生隔离：
- Linux 用 **Bubblewrap**（bwrap），macOS 用 **Seatbelt**
- CPU/内存/时长 + 网络三档控制
- 能塞进 serverless 环境
- 三档安全策略：标准（直接执行）→ 严格（沙箱审批）→ 锁定（人工审核），按风险自动升级
- 否决账本：连续 3 次被拒→自动暂停执行，防止"暴力穷举"绕过
- 防引用绕过：被拒绝操作结果立即清除缓存
- Prompt 注入防护：所有技能描述和工具结果 XML 转义处理

### 6. 微内核架构：小核心，大生态
借鉴操作系统微内核思想——核心编排器只做最少的事：编排调度和状态管理（百行级），其余能力全部以插件形式在"用户态"运行：
- ServiceContainer 依赖注入中枢
- TurnRunner 统一执行管道（状态机驱动，全异步，出错自动回滚）
- 想换 LLM 供应商？实现一个 Protocol 即可
- 想加新工具？写 5 行 duck-typed 类即可，不继承基类、不发包、不写 manifest
- 插件崩溃不影响核心，核心升级不破坏插件

### 7. 多渠道即插即用
一个 Agent 配好，10+ 渠道同时接入：Terminal、Web UI、Slack、Discord、Telegram、MS Teams、Matrix、飞书、钉钉、企业微信、QQ。ChannelManager 管理生命周期，渠道即插即用。

## 技术亮点

### 1. SquillaRouter 的 V4Phase3 策略：从 NL 到 ML 的三级管道
SquillaRouter 不止是"看一眼就选模型"，而是 V4Phase3 策略的三级管道：
- **Context Assembly**：InferenceRequest 收集当前消息、路由历史、上下文 Token 数
- **Model Inference**：InferenceCore 用 LightGBM（lgbm_main.bin）+ ONNX 模型做双引擎推理
- **Post-Processing**：概率向量推导 thinking_mode（T0-T3）+ prompt_policy（P0-P2），低置信度时注入 `[RESPONSE_POLICY: Answer directly]` 等策略指令

如果 ML 模型资产缺失（Windows 缺 VC++ Redistributable 等），系统回退到 `_unavailable_classify`，默认安全 tier c1 并日志警告——从不崩溃，只是降级。

### 2. 记忆分层与 Dream 整合的工程实现
MemoryManager 协调本地 workspace 文件和向量数据库。Markdown 文件是知识的事实之源，MemorySyncManager 跟踪文件 hash 和 mtime 硓持 SQLite 索引同步。向量存储前自动 L2 归一化确保 cosine 相似度准确性。SessionFlushService 把 session transcript 转入 memory/ archives，原始 fallback 不进入语义索引避免污染知识库。

Dream 整合两阶段：Phase 1 用 LLM 分析 transcript 提取常青事实；Phase 2 用子 Agent 精确编辑 MEMORY.md，带 session locking 防并发冲突。这是认知科学"睡眠巩固"的工程化实现——不是简单的"总结存库"，而是从 volatile → persistent → semantic 的分层升华。

### 3. 微内核的可观测性与合规审计
决策日志存 hash 不存原文——天然合规审计，管线每个环节强制留痕。每次调用自带实付金额，可挂额度钩子用超自动断流。成本追踪不是事后统计，而是运行时内嵌——Agent 用超预算会自动停止，不是跑完再告诉你花了多少。

## 适用人群

1. **预算敏感的开发者/团队**：同样的钱跑更多任务，智能路由自动选最划算的模型
2. **私有化部署需求企业**：完全离线运行，数据不出内网，ML 路由本地推理，ONNX 嵌入 CPU 可跑
3. **合规审计场景**：三档安全策略 + 决策日志哈希脱敏 + 人工审批闸门

5. **需要 Agent 持久记忆的用户**：四层类人记忆自动积累上下文，不再每次从零开始
6. **Agent 自进化研究者**：MetaSkills 协议 + 梦境模式，Agent 在后台悄悄长出新能力

## 快速上手

```bash
# 方式1：终端一键安装（推荐，所有平台）
uv tool install --python 3.12 "opensquilla[recommended] @ https://github.com/opensquilla/opensquilla/releases/download/v0.3.1/opensquilla-0.3.1-py3-none-any.whl"

# 方式2：Windows 便携包（免装 Python）
# 下载 OpenSquilla-windows-x64-portable.zip → 解压 → 右键 Start OpenSquilla.cmd 以管理员运行

# 方式3：源码安装
git lfs install && git clone https://github.com/opensquilla/opensquilla.git
cd opensquilla && git lfs pull --include="src/opensquilla/squilla_router/models/**"
bash scripts/install_source.sh

# 配置并运行
opensquilla onboard           # 交互式配置向导
opensquilla gateway run       # 启动 ASGI 服务
# 打开 http://127.0.0.1:18791/control/
```

### 与同类 Agent 框架逐项对比

| 维度 | **OpenSquilla** | OpenClaw | Hermes Agent |
|------|-----------------|----------|-------------|
| 架构 | ✅ 微内核5层分离，百行级核心 | ⚠️ 插件生态成熟但层级偏多 | ❌ 单体同步主循环，逻辑耦合 |
| 高效省钱 | ✅ ML路由+思维分级+技能按需加载，省60-80% | ⚠️ 配置写死模型，不看内容自动选 | ⚠️ 关键词+字数粗糙判断 |
| MetaSkills | ✅ 可组合+meta-skill-creator自进化+梦境凝练 | ⚠️ Prompt串联skill chain，无自我进化 | ❌ 无可复用工作流抽象 |
| 记忆 | ✅ 四层认知+Dream+冒泡+衰减+混合检索 | ⚠️ 衰减/冒泡有，缺四层结构与Dream | ⚠️ 仅关键词搜索，无向量语义 |
| 安全沙箱 | ✅ 系统调用级隔离，不依赖Docker | ⚠️ Docker可选，OpenShell轻量替代 | ✅ 危险命令审批+6种执行环境 |
| 成本追踪 | ✅ 每调用自带实付金额+额度钩子 | ✅ 内置价格表+会话元数据 | ✅ 五项Token统计 |
| 可观测性 | ✅ 决策日志hash+管线强制留痕 | ✅ OpenTelemetry原生 | ⚠️ SQLite会话表，较基础 |
| 扩展开发 | ✅ 5行duck-typed类，无基类/manifest | ⚠️ plugin-sdk接口+manifest清单 | ⚠️ import时隐式注册全局表 |
| 渠道 | ✅ 10+（飞书/钉钉/企微/QQ等） | ✅ 多渠道支持 | ⚠️ Web+CLI为主 |

### 成本影响估算
以典型开发者工作日为例（50 次交互）：
- 20 次简单问答（c0-c1 级）：传统方案用强模型 ~$6，OpenSquilla 用 flash 模型 ~$0.6
- 20 次中等任务（c2 级）：两边用平衡模型，成本相近 ~$3
- 10 欠复杂推理（c3 级）：两边都用强模型，但 OpenSquilla 自适应 Prompt 减少 Token ~$2 vs ~$3

- 加上思维深度分级（简单问答不开推理 Token）+ 技能按需加载（不一股脑塞所有能力），综合节省 **60-80%**
