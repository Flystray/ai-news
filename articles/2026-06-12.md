# reasoning-from-scratch：Sebastian Raschka 手把手教你从零构建推理模型

> 📅 2026-06-12 | ⭐ 4,474 | 🔤 Jupyter Notebook / Python | 🔗 [GitHub](https://github.com/rasbt/reasoning-from-scratch)

## 项目背景

2025年初，DeepSeek R1 的发布震动了整个 AI 界——一个开源模型通过"推理时思考"实现了与闭源模型媲美的能力。随后 OpenAI 的 o1/o3、Anthropic 的扩展思考、GPT-5 Thinking 等现象级产品的涌现，让"推理模型"成为 LLM 领域最炙手可热的方向。

但问题来了：**大多数开发者只能调用 API，对推理模型内部机制一知半解**。GRPO 强化学习、推理时扩展（Inference-Time Scaling）、知识蒸馏——这些术语满天飞，但真正理解并能亲手实现的人少之又少。

**reasoning-from-scratch** 正是为解决这个痛点而生。它由世界级 AI 教育者 **Sebastian Raschka** 博士撰写，是 Manning 出版社发行的《Build a Reasoning Model (From Scratch)》一书的官方配套代码仓库。项目的核心哲学简单直接：**理解推理技术的最佳方式，就是从零开始编码实现它**。

> "这本书不仅解释推理模型，还让你能够从第一性原理构建、测试和真正理解它们。" —— Aman Chadha, Google DeepMind 高级技术主管

> "我见过的关于推理模型最好的资源之一。" —— Ivan Leo, Google DeepMind 技术团队

Raschka 此前已凭借《Build a Large Language Model (From Scratch)》（⭐ 34k+）成为 LLM 教育领域的标杆人物。这本新书是他的进阶之作——如果说前作是"从零构建 LLM 基础"，那本书就是"在 LLM 之上叠加推理能力"。

截至 2026 年 6 月，项目已获得 **4,474 Stars、659 Forks**，288 次提交，配套 PyPI 包 `reasoning-from-scratch` 可直接安装，Apache 2.0 许可证完全开放。

## 核心功能

### 1. 渐进式八章学习路径（主线）

项目以交互式 Jupyter Notebook 为载体，从零开始逐步培养推理模型开发能力：

| 章节 | 主题 | 核心收获 |
|------|------|----------|
| Ch1 | 理解推理模型 | 建立对推理模型的宏观认识，了解完整技术路线图 |
| Ch2 | 文本生成基础 | 使用预训练 LLM（Qwen3）进行文本生成，搭建 Python/GPU 环境 |
| Ch3 | 评估推理模型 | 构建 MATH-500 评估框架，设计解析器和验证器 |
| Ch4 | 推理时扩展基础 | 实现思维链（CoT）、自一致性（Self-Consistency）、多数投票 |
| Ch5 | 高级推理时扩展 | 自我优化（Self-Refinement）、Best-of-N 采样策略 |
| Ch6 | GRPO 强化学习基础 | 首次引入 RL，从零实现 GRPO 训练循环 |
| Ch7 | 高级 GRPO 优化 | DeepSeek-V3.2 风格、Olmo3 风格训练，含 KL 散度约束 |
| Ch8 | 知识蒸馏 | 大推理模型 → 小模型的蒸馏数据生成与训练 |

每章都配有习题解答（Exercise Solutions），形成"阅读→编码→练习"三步学习闭环。

### 2. 六大附录——从源码到生产

除了主线的 8 章，项目还提供了 6 个附录，覆盖从底层实现到实际部署的全链路：

- **附录 C：Qwen3 完整源码实现**——从零构建 Transformer 架构，连接教育代码与真实开源模型
- **附录 D：使用更大规模 LLM**——将推理方法扩展到更大模型
- **附录 E：批处理与吞吐量优化**——生产环境下的性能调优
- **附录 F：LLM 评估方法大全**——MMLU、LLM 排行榜、LLM-as-a-Judge 等工业级评估方案
- **附录 G：构建聊天界面**——为推理模型搭建可交互的 Chat UI

### 3. GRPO 强化学习——DeepSeek R1 核心技术的完整实现

GRPO（Group Relative Policy Optimization）是 DeepSeek R1 取得突破性推理能力的关键技术。本书用整整两章（Ch6 + Ch7）对其进行从零实现：

- **Ch6**：实现基础 GRPO 训练循环，介绍奖励函数设计、策略优化基础
- **Ch7**：深入高级 GRPO 技巧，包括 KL 散度约束惩罚、DeepSeek-V3.2 和 Olmo3 风格的多变体实现
- **配套资源**：提供 HuggingFace 上的 [GRPO 训练检查点](https://huggingface.co/rasbt/qwen3-from-scratch-grpo-checkpoints) 供直接下载实验

### 4. 推理时扩展（Inference-Time Scaling）全景

本书在 Ch4-Ch5 系统覆盖了推理时扩展的完整技术栈：

- **思维链（Chain-of-Thought）**：引导模型生成中间推理步骤
- **自一致性（Self-Consistency）**：生成多条推理路径，投票选出最佳答案
- **自我优化（Self-Refinement）**：让模型审视并迭代改进自己的输出
- **Best-of-N**：生成 N 个候选结果，选择最优解

这些方法通过让模型在推理阶段"多想一想"，在不改变模型权重的前提下显著提升数学推理能力。

### 5. 知识蒸馏——把小模型变成推理高手

第 8 章聚焦推理模型的蒸馏技术：

- 使用大型推理模型（教师）生成高质量推理数据集
- 通过蒸馏训练将推理能力迁移到小型模型（学生）
- 配套蒸馏数据生成脚本和训练代码
- 提供蒸馏后的检查点供直接使用

蒸馏后的模型在保持较小体积的同时，获得远超同规模模型的推理能力，特别适合资源受限的部署场景。

## 技术亮点

### 1. 三层架构：教学性 × 生产级代码质量

项目采用清晰的三层分离架构，在"易于理解"和"代码规范"之间取得精妙平衡：

- **教育内容层**（`.ipynb` Notebook）：用户交互的主要入口，逐行解释每一步的操作和原理
- **核心实现层**（Python 模块）：Qwen3 模型、分词器、GRPO 训练循环等独立模块，可直接导入复用
- **质量保障层**：CI 流水线覆盖 Linux/macOS/Windows 三平台 + Python 3.10-3.13 多版本测试

### 2. 消费级硬件友好——人人可复现

项目的设计底线是**消费级硬件可运行**：

- 第 2-4 章在纯 CPU 上即可流畅执行（推理时扩展不需要训练）
- 第 5-7 章推荐 GPU，但代码会自动检测设备并回退到 CPU
- 基础模型选用 Qwen3（而非超大模型），确保内存需求可控
- 所有代码均在生产级硬件上验证可运行

### 3. 与前沿模型的"原理对齐，非复现"

项目**不是**去复现 DeepSeek R1 或 GPT-5 Thinking 的完整训练——这在消费级硬件上本就不可能。而是通过亲手实践，让你**真正理解**驱动这些前沿模型的核心原理：

| 前沿模型 | 本书覆盖的核心技术 |
|----------|-------------------|
| DeepSeek R1 | GRPO 强化学习、推理时扩展 |
| GPT-5 Thinking | 推理时扩展、自我优化 |
| DeepSeek R1 蒸馏版 | 知识蒸馏 |

这种"对齐原理、降低门槛"的设计哲学，让学习者在没有万卡集群的情况下，也能真正搞懂推理模型的工作原理。

## 快速上手

```bash
# 1. 克隆仓库
git clone --depth 1 https://github.com/rasbt/reasoning-from-scratch.git
cd reasoning-from-scratch

# 2. 安装依赖
pip install -r requirements.txt

# 3. 安装 PyPI 包（可选）
pip install reasoning-from-scratch

# 4. 启动 Jupyter，从 Ch2 开始
jupyter notebook ch02/ch02_main.ipynb

# 5. 前4章 CPU 即可运行，Ch5+ 推荐 GPU
```

硬件要求：前 4 章在 CPU 上即可流畅运行；第 5-7 章的 GRPO 训练推荐使用 GPU（代码会自动检测可用设备）。
