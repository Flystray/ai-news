FinceptTerminal

⭐ 19.4k 🍴 2.6k 📄 AGPL-3.0
访问 GitHub 仓库

💡 一句话介绍

开源金融终端，Bloomberg 的开源替代方案。C++20 + Qt6 原生架构，内置 37 个 AI 投资智能体和 100+ 数据连接器，年省 $27,000 订阅费。

🎯 项目背景

金融数据终端是投资研究的核心基础设施，但传统方案存在明显痛点：Bloomberg Terminal 年费高达 $27,000，且生态封闭、无 API、厂商锁定严重。

FinceptTerminal 应运而生——它不是"廉价版 Bloomberg"，而是一个可扩展的开源金融研究平台，用 C++20 + Qt6 原生架构重构金融终端体验。

🛠️ 技术栈

C++20 Qt6 Python 3.11 CMake Ninja

架构亮点：C++20 + Qt6 构建原生 UI，嵌入式 Python 3.11 作为分析引擎，零 Web 技术开销，启动 < 2 秒，安装包 < 50MB。

✨ 核心功能（8大模块）

📊 多资产分析

DCF模型、投资组合优化、VaR风险指标、衍生品定价

🤖 AI智能体系统

37个AI Agent，覆盖Buffett、Graham等投资大师思维框架

🌐 数据连接器

100+数据源：Polygon、Yahoo Finance、IMF、World Bank、AkShare

💹 实时交易

16家券商集成，支持加密货币/股票实盘交易、算法交易

📈 QuantLib套件

18个定量分析模块：定价、风险、随机过程、波动率

🌍 全球情报

海事追踪、地缘政治分析、关系图谱、卫星数据

🎨 可视化工作流

节点编辑器拖拽构建自动化分析/交易流程

🔬 AI量化实验室

机器学习训练、因子发现、高频交易、强化学习优化

🤖 AI能力详解

FinceptTerminal 的核心差异化能力——将投资大师的思维框架编码为可执行 AI Agent：

  • 价值投资框架：Buffett、Graham、Lynch、Munger、Klarman、Marks
  • 宏观分析框架：经济周期预测、货币政策解读
  • 地缘政治框架：全球政治风险评估、事件驱动分析

支持的 LLM 提供商：OpenAI、Anthropic、Gemini、Groq、DeepSeek、MiniMax、OpenRouter、Ollama（本地部署）
