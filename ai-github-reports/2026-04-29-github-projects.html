GenericAgent

自进化通用智能体：仅 3K 行核心代码，让任何 LLM 获得完整的系统级控制能力，并自动将任务执行路径结晶为可复用的"技能树"

⭐ 8.0k 🍴 920+ 📝 Python 🕐 活跃于今天 📄 MIT 🔗 lsdefine/GenericAgent
agent autonomous self-evolving llm browser-automation

💡 自举证明：该项目本身的所有 Git 操作——包括 git init、代码提交和 commit message——全部由 GenericAgent 自主完成，无需人工终端干预。这是"自进化"理念的最佳证明。

当前 AI Agent 框架普遍面临两个矛盾：能力越强代码越臃肿（如 OpenClaw 约 53 万行）、上下文越长幻觉越多成本越高（主流方案需 200K-1M token）。GenericAgent 提出"极简自进化"范式——不预加载技能，让 Agent 自己进化出技能。核心仅 ~3K 行代码，Agent 循环仅 ~100 行。

🚀 核心功能

  • 自进化机制 — 每次执行任务后，自动将执行路径"结晶"为可复用的 Skill；使用越久，能力越强，从 3K 行种子代码生长出个性化技能树
  • 极简架构 — ~3K 行核心代码 + ~100 行 Agent 循环 + 9 个原子工具，零复杂依赖
  • 真实浏览器注入 — 直接注入真实浏览器（保留登录会话），区别于沙箱/无头方案
  • 多层记忆系统 — L0 元规则 → L1 洞察索引 → L2 全局事实 → L3 任务技能/SOP → L4 会话归档，五层记忆分层存储
  • Token 高效 — 上下文窗口 <30K（对比主流方案的 200K-1M），token 消耗降低约 6 倍，同时减少幻觉
  • 全平台兼容 — 支持 Claude、Gemini、Kimi、MiniMax 等主流 LLM 模型；跨平台运行
  • 多前端支持 — Streamlit Web UI、Qt 桌面应用、微信/QQ/Telegram/飞书/钉钉 Bot

⚙️ 技术亮点

  • 9 个原子工具覆盖完整系统控制：code_run（执行任意代码）、file_read/write/patch（文件操作）、web_scan（网页感知）、web_execute_js（浏览器控制）、ask_user（人工确认）、记忆管理工具。通过 code_run 还可动态安装包、调用 API、控制硬件——临时能力可被"结晶"为永久工具
  • 动态工具创建 — 运行时通过 code_run 创建新工具，随后自动"结晶"为永久可用工具，实现能力的持续增长
  • 论文 + 社区支持 — 已发布技术报告（arXiv: 2604.17091），有 Datawhale 社区教程和百万级技能库
