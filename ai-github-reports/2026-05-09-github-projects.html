AI 编程助手能写代码，但写不出好设计——配色随机、字体不协调、风格不一致。根本原因：AI 生成 UI 时缺乏结构化的设计知识库参照。本项目不走"给人类做设计工具"的老路，而是构建了一个"给 AI 用的设计知识库"，通过推理规则引擎让 AI 不仅知道有哪些设计资源，还知道在什么场景下应该用哪些资源。

📌 项目背景

AI 编程助手（Claude Code、Cursor、Windsurf 等）在代码生成方面已经相当成熟，但UI/UX 生成质量一直是短板。根本原因在于：AI 在生成 UI 时缺乏结构化的设计知识库可以参照——就像让一个没有学过设计理论的程序员凭直觉画界面一样。

传统解决方案是人工编写设计系统文档或购买设计库，但这两者都是"人读"的格式，AI 无法直接利用。UI UX Pro Max Skill 的创新之处在于：构建了一条从"设计知识检索"到"设计决策推理"再到"设计系统输出"的完整链路。

知识库（344+ CSV） → 搜索引擎（BM25 + 领域检测） → 推理引擎（161 条规则） → 设计系统生成器（Master+Overrides）

v2.0（2026 年 3 月）新增了推理规则引擎和 161 条行业推理规则，标志着项目从"设计资源检索工具"进化为"设计智能引擎"。

🚀 核心功能

  • 344+ 结构化设计资源数据库 — 覆盖 10 个设计领域、16 种技术栈：67 种 UI 风格、161 套行业配色、57 组字体搭配、25 种图表类型、99 条 UX 指南、161 条行业推理规则。所有数据以 CSV 格式存储——对 Git diff 友好、可被非技术用户编辑、支持大规模扩展。
  • 智能设计系统生成器（v2.0 旗舰） — 推理引擎分析项目需求，秒级生成完整定制化设计系统规范：多领域联合搜索 → 推理规则应用 → Master + Overrides 模式输出。包括 24 种布局模式推荐、配色方案、字体搭配、动效参数、反模式警告。
  • 推理规则引擎（Reasoning Engine） — v2.0 最核心的创新。不同于简单关键词匹配，能根据上下文进行设计决策推理：输入"SaaS 着陆页"→ 推理出"需要信任元素"→ 搜索 testimonials 模式 → 推理出"需要 CTA 转化"→ 搜索 conversion patterns → 输出完整方案。161 条行业规则覆盖 SaaS/医疗/电商等场景。
  • BM25 智能搜索引擎 — 在 scripts/core.py 中完整实现 BM25 算法（k1=1.5, b=0.75），包含分词器、TF-IDF 评分、领域自动检测和技术栈过滤。相比简单搜索，相关度提升约 60%。同时提供 CLI 接口（search.py）。
  • 18+ AI 平台全覆盖 — 同时支持 Claude Code、Cursor、Windsurf、Codex CLI、GitHub Copilot、Gemini CLI、Kiro、Roo Code 等。通过 JSON 配置文件实现平台适配，新增平台只需添加一个 JSON 配置。
  • 零配置平台自动检测 — CLI 工具扫描项目目录特征自动识别 AI 平台：.claude/ → Claude Code，.cursor/ → Cursor，.windsurf/ → Windsurf 等。用户只需 uipro init，无需指定平台。
  • Master + Overrides 设计系统架构 — 基础规范保存在 MASTER.md，页面覆盖规则保存在 pages/*.md，保证设计一致性的同时支持技术栈定制。首次在 AI 辅助设计工具中实现。
  • 预交付质量检查清单 — 自动检查无障碍性（对比度 ≥ 4.5:1）、性能优化（WebP/AVIF）、交互规范（触控目标 ≥ 44px）、视觉一致性。

⚙️ 技术亮点

  • 推理规则引擎：从"搜索"到"推理"的范式升级 — 传统设计工具只能搜索已有资源，而本项目的推理引擎能进行上下文感知的设计决策推理。技术实现：接收需求 → 多领域联合搜索 → 应用 reasoning_rules 推理规则 → 决策树推理 → 多领域数据合成 → 输出一致性设计系统。这种"检索 + 推理"架构，使 AI 不仅知道有哪些设计资源，还知道在什么场景下应该用哪些资源。
  • CSV 作为知识库格式的设计工程化实践 — 看似简单的 CSV 选择实则精妙：① 纯文本对 Git diff 友好，社区贡献者可像审查代码一样审查设计知识变更；② 可被非技术用户直接用 Excel 编辑；③ 可被 BM25 算法高效索引和查询；④ 通过列定义属性和关系，支持领域权重调整和技术栈相关性评分。这是"设计工程化"（Design Engineering）的创新实践——将设计知识像代码一样管理。
  • 双模式平台集成 + 符号链接开发架构 — Skill 模式（full 类型，完整知识库，自动激活）+ Workflow 模式（reference 类型，轻量引用，手动触发），优化不同平台的上下文窗口使用。开发层面，符号链接实现 src/ui-ux-pro-max/ ↔ .claude/ ↔ .shared/ 实时同步，修改一处代码，所有平台配置自动生效。

⚡ 快速上手

方式一：通过 CLI 安装（推荐，零配置）

# 全局安装 CLI 工具 npm install -g uipro-cli # 进入项目目录并初始化（自动检测 AI 平台） cd /path/to/your/project uipro init # 自动检测 .claude/、.cursor/ 等目录 uipro init --ai claude # 或手动指定平台

方式二：直接在 Claude Code 中使用（安装后自动激活）

Build a landing page for my SaaS product with hero section, features, testimonials, and pricing table. # AI 自动执行完整链路： # ① 平台检测 → ② BM25 搜索 → ③ 多领域查询 # → ④ 推理规则应用 → ⑤ 设计系统生成 → ⑥ 输出方案

方式三：CLI 直接生成设计系统

# 生成 Markdown 格式设计系统 python3 .claude/skills/ui-ux-pro-max/scripts/search.py \ "fintech banking app" --design-system -f markdown # 持久化设计系统到文件（生成 MASTER.md + pages/*.md） python3 .claude/skills/ui-ux-pro-max/scripts/search.py \ "SaaS dashboard" --design-system --persist -p "MyApp"
