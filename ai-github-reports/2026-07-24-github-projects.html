项目概览：stablyai / orca

ADE Y Combinator MIT 2026-03

Orca 是一款开源的 Agent Development Environment（ADE），定位为"AI 编码 agent 的调度中心"。 它允许开发者在相互隔离的 git worktree 中并行运行 Claude Code、Codex、OpenCode、Pi 等 30+ 个 CLI agent， 统一监控状态、比较输出、合并最优结果，并通过移动端 App 实现远程管理。

核心功能

1. 并行 Worktree：一个 prompt 扇出多个 agent

将同一任务同时交给多个 agent，每个 agent 在独立 git worktree 中实现，完成后并排比较、择优合并。无需 stash，无需手动切分支。

2. Agent 舰队状态监控

主界面实时显示所有 worktree 中 agent 的 working / idle / blocked / done 状态，卡住一眼可见。

3. 移动端伴侣 App

iOS（App Store / TestFlight）与 Android（APK）支持，出门也能查看 agent 进度、接收通知、发送 follow-up 指令。

4. Design Mode

每个 worktree 内置 Chromium 浏览器，点击任意 UI 元素即可把 HTML、CSS 与截图直接送入 agent prompt，视觉修改反馈闭环。

5. AI Diff 批注回传

在 diff 任意一行写 markdown 批注，批量回传给 agent 修改，把 code review 做进 agent 工作流。

6. GitHub & Linear 原生集成

应用内浏览 PR、issue、Project 看板，直接从任务打开 worktree，支持 CI 检查与 PR 创建。

7. SSH Worktrees

把 agent 派到远程机器运行，支持文件编辑、git、终端，断线自动重连，带端口转发。

8. Orca CLI

提供 orca worktree create、snapshot、click、fill 等命令，agent 也能反向控制 IDE。

技术亮点

Electron 三进程架构

Main 进程负责原生集成（Git、PTY、SSH）与持久化；Preload 通过 contextBridge 暴露安全 API；Renderer 用 React + Zustand 渲染。系统级操作不阻塞 UI。

Ghostty 级终端体验

基于 xterm.js + node-pty，WebGL 渲染，支持无限分屏、重启后 scrollback 恢复、全量搜索。

版本化持久化层

Store 类管理 orca-data.json，支持 schema 版本控制与迁移，保证配置向前兼容。

"自带订阅"的中立定位

Orca 不卖模型 token，只提供编排层。用户自带 Claude / Codex 等订阅，因此能同时支持 30+ CLI agent，避免被单一厂商锁定。

一句话总结：Orca 不是替代某个 agent，而是把多个 agent 组织成可监控、可比较、可合并的舰队。

核心差异：主流工具竞争的是"单个 agent 的能力"，Orca 竞争的是"多个 agent 的编排效率"。 它适合已经持有多个 agent 订阅、希望把它们组织成并行工作流的重度用户。

快速上手

# macOS
brew install --cask stablyai/orca/orca

# Arch Linux
yay -S stably-orca-bin

# Windows / Linux 下载安装包
# https://onorca.dev/download

安装后登录已安装的 agent，创建 workspace，新建 worktree 并启动 agent；使用"Duplicate to N agents"把同一 prompt 扇出到多个 agent，最后比较 diff 合并最优版本。

适用人群

  • 多 agent 订阅用户：同时持有 Claude、Codex、Cursor 等，需要统一调度
  • 并行实验型开发者：同一任务想比较多个 agent 实现，择优合并
  • 多仓库/多分支团队：需要隔离的 worktree 并行推进需求
  • 远程开发者：需要在服务器跑 agent 或出门在外监控进度
  • 终端体验敏感用户：喜欢 Ghostty/Warp 级终端，又需要 AI 工作流整合

局限与风险

  1. 项目较新：2026 年 3 月创建，API 与插件生态仍在快速迭代
  2. Electron 体量：功能丰富但资源占用高于纯终端工具
  3. 大厂追赶：VS Code、JetBrains、Cursor 可能将多 agent 工作流做进原生界面
  4. 订阅成本：Orca 免费，但每个 agent 仍需单独付费
