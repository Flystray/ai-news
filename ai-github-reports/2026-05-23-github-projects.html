ARIS（Auto-Research-In-Sleep）是上海交通大学开源的自主 ML 研究框架，通过跨模型对抗协作解决长程 Agent 的"虚假合理性"问题。核心理念：让 Claude Code 执行研究，让 GPT-5.4 审查挑刺，两个不同家族的模型互相对抗，把分歧暴露出来。整个系统由 74 个 Markdown 文件组成，零依赖、零锁定。

📌 项目背景

当 AI Agent 尝试自主完成长周期科研任务时，最大的问题不是"跑不下去"——而是"看起来很对，其实全错"。长时间运行的 Agent 会产生表面合理但证据不完整或暗含执行模型自身预设偏见的结论，这种"虚假合理性"（Plausible Hallucination）是自主科研领域的核心瓶颈。


ARIS 由上海交大李帅课题组（杨若枫、李永灿、李帅）开发，2026 年 5 月上传 arXiv 论文（2605.03042），当天登上 Hugging Face Daily Papers 第一名（68 赞）。arXiv 编号末尾的 .03042 意味着这是 5 月 6 日当天的第 42 篇投稿——当天竞争最激烈的一天之一。

核心洞察：长周期 Agent 的瓶颈不是能力，是可信度。ARIS 不追求"让 Agent 跑得更远"，而专攻"如何发现并纠正 Agent 在长程研究中产生的虚假合理性"。

💡 技术亮点

  • "分歧即真相"跨模型对抗：强制执行模型（Claude）和审查模型（GPT）来自不同家族。类比随机 Bandit vs 对抗 Bandit——两人博弈比 n 人博弈更高效收敛到 Nash 均衡。审查者可自己跑代码、读数据、写测试用例
  • 三阶段证据-主张审计级联：实验审计（伪标签/幽灵结果/未执行指标） → 结果到主张映射（支持度判定） → 全新审查者终审（无上下文，只看原始结果 vs 论文定量主张）
  • 纯 Markdown Skills（零依赖哲学）：74 个 SKILL.md 文件，无框架/数据库/Docker/守护进程。热替换、跨模型通用、30 分钟通读全部逻辑。"方法论，不是平台"——可移植到 Codex CLI、Cursor、Trae、Antigravity
  • 持久 Research Wiki：失败进禁试清单、成功进起点池，螺旋式累积学习。Meta-Optimization 外循环自动分析日志改进 Skills
  • 五轮科学编辑流水线：冗余→主动语态→局部连贯→术语一致→数字一致，确保论文质量
  • 9+ 种模型组合：含全免费方案（ModelScope 2000 次/天）、国内方案（阿里 Coding Plan 一键四模型）

⚠️ 局限性（作者自述）

  • 观察性证据 ≠ 因果证据，不能严格证明跨家族审查一定优于同家族
  • 可能 3 个、4 个 Reviewer 效果更好，当前只验证了双模型
  • 降低幻觉概率，但不消除幻觉
  • 仓库级审查需把代码给外部 API，本地审查路由仍在规划中
