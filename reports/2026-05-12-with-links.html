OpenAI 核心研究员翁家翌提出"启发式学习"新范式，无需梯度下降也能突破 Atari 满分

OpenAI 后训练核心成员翁家翌通过个人研究提出了一种名为"启发式学习"（Heuristic Learning）的全新强化学习范式。核心思路是：当 Coding Agent 足够强之后，过去维护不起的复杂策略，现在可以完全用代码表达。实验中，这套纯代码系统在经典 Atari 游戏中打出了理论最高分，在机器人控制任务中达到了媲美深度强化学习的成绩，全程没有神经网络、没有梯度下降、没有任何"训练"过程。这可能意味着 AI 训练范式的根本性变革。

  • 无需神经网络和梯度下降，纯代码实现 AI 自我迭代
  • Atari 游戏打出理论最高分，机器人控制媲美 Deep RL
  • 核心理念：用 Coding Agent 直接编写和优化决策代码
  • 可能解决持续学习中"灾难性遗忘"这一长期难题

综合分析 技术范式

"启发式学习"挑战梯度下降正统地位，AI 训练范式可能迎来根本变革

OpenAI 核心研究员翁家翌的"启发式学习"实验，用纯代码、无神经网络、无梯度下降的方式在 Atari 游戏中打出理论最高分，这一结果令人深思。如果 Coding Agent 足够强大，传统强化学习的复杂策略优化是否可以被代码本身替代？这不仅是对训练效率的优化，更是对"什么是智能"这一根本问题的重新审视。虽然距离大规模实用尚有距离，但这项研究至少证明了一点：我们习以为常的"梯度下降 + 神经网络"范式，可能不是 AI 进化的唯一路径。

  • 纯代码、无神经网络达到理论最高分，颠覆性实验结果
  • 核心思路：用 Coding Agent 编写和优化决策代码，绕过训练过程
  • 可能解决持续学习中"灾难性遗忘"的长期难题
  • 挑战"梯度下降 + 神经网络"的 AI 训练正统范式
综合分析 政策信号

AI 智能体专项政策出台：中国监管从"管模型"走向"管行为"

三部门联合印发的《智能体规范应用与创新发展实施意见》，代表了中国 AI 监管思路的重要转变。此前监管重心在"管模型"——审批模型上线、限制生成内容；现在开始"管行为"——为具备自主执行能力的 AI Agent 划定行为边界。文件中"安全可控、规范有序"的要求意味着：智能体可以自主行动，但不能失控；可以创新应用，但不能触碰底线。在全球范围内，中国率先为 AI Agent 专项立法，这一举措可能成为各国监管的参考范本。

  • 监管重心从"管模型"转向"管行为"，为 AI Agent 划定边界
  • 中国率先为 AI Agent 出台专项国家级政策
  • "安全可控 + 创新驱动"双轨并行，不是一刀切
  • 可能成为各国 AI 智能体监管的参考范本
