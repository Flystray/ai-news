📌 项目背景

在 2025–2026 年大模型 Agent 浪潮中，"提示词"逐渐演化为"可被工程化调度的角色资产"。GitHub 上英文圈最火的项目是 msitarzewski/agency-agents，但其角色全部围绕北美 SaaS 场景：CRM、SEO、SaaS 增长、Stripe 集成……对中国开发者来说，"小红书种草"、"抖音电商"、"飞书机器人"、"政务 ToG 投标准备"、"医疗合规审查"等高频场景完全缺失。

agency-agents-zh 正是为填补这一空缺而诞生的中文社区版。它做的事情有三件：

① 完整翻译上游 215 个英文角色（保留原文专业度，附中文 SOP）

② 原创 50 个中国市场专属角色（小红书 / 抖音 / 微信 / B 站 / 飞书 / 钉钉 / 跨境电商 / 政务 ToG / 医疗合规 / Qt 工业上位机 / 高考志愿填报等）

③ 构建 NEXUS 多智能体编排框架，把"专家库 + 工具链 + 生命周期管理"打包成一个可持续演进的开源生态

📚 Layer 1 · Agent Library：18 个部门 / 266 个 .md 角色定义（YAML frontmatter + 结构化正文）
⚙️ Layer 2 · Conversion & Installation Pipeline：convert.sh 解析 → 工具专属格式 / install.sh 检测本地环境 → 智能部署
🔗 Layer 3 · NEXUS Orchestration Framework：7 阶段生命周期 + 3 激活模式 + 4 套场景剧本
🎯 NEXUS 7 阶段：Discovery → Strategy → Foundation → Build → Hardening → Launch → Operate
🧠 质量门禁：Evidence Over Words 原则 · Dev-QA Evidence Loop · Pipeline Integrity
🌐 17 工具适配：OpenClaw / Claude Code / Cursor / Copilot / WorkBuddy / Hermes Agent / DeerFlow 2.0…

🚀 核心功能

🎭 266 个即插即用专家

每个角色都带"身份 + 工作流 + 交付物 + 红线"四件套，远超"你是一个 X 专家"的浅层提示词。覆盖工程/设计/营销/金融/法律/供应链/游戏/空间计算等 18 个部门。

🛠️ 17 工具一键安装

install.sh --tool <name> 自动检测本地 IDE/CLI（Claude Code、Cursor、Copilot、Trae、Windsurf、Codex、WorkBuddy、Hermes Agent、DeerFlow 2.0 等），部署到对应配置目录。

🎯 NEXUS 7 阶段编排

Discovery → Strategy → Foundation → Build → Hardening → Launch → Operate，配合 "Evidence Over Words" 质量门禁，不达标不能进入下一阶段。

⚡ 三种激活模式

NEXUS-Full（190+ 智能体，12-24 周企业级）/ NEXUS-Sprint（15-25 个，2-6 周 MVP）/ NEXUS-Micro（5-10 个，1-5 天单任务）。

📜 4 套场景剧本

创业 MVP、企业级 Feature、营销 Campaign、Incident Response 标准化 runbook，提供"开箱即用"的多 Agent 协作模板。

🧩 Agency Orchestrator

配套 npm 包，支持 ao compose "<任务>" --run 一句话调度多 Agent。10 家 LLM / 7 免费模型可选。

✨ 技术亮点

1. Role-as-Code 工程化

每个 .md 文件有严格 YAML frontmatter（name / department / role / tools 等字段），由 scripts/lint-agents.sh 自动校验字段完整性，从源头杜绝"半成品 prompt"。

2. 两层流水线架构

convert.sh：解析 Markdown → AST → 工具专属格式（.mdc / .json / CONVENTIONS.md）。
install.sh：检测本地环境（~/.claude/agents/、.cursor/rules/ 等）→ 智能复制到目标目录。

3. NEXUS 编排协议

通过 "Pipeline Integrity" 原则保证阶段间不丢失上下文；Dev-QA Evidence Loop 让工程类智能体与 reality-checker 配对运行，避免"看起来对但实际坏掉"的交付。

4. OpenClaw 优先适配

将每个角色拆为 SOUL.md（人设）+ AGENTS.md（业务能力）+ IDENTITY.md（简介）三件套，与 OpenClaw 的子代理调度深度协同。

👥 适用人群

  • 个人开发者 / 独立创业者：1 个人想当 10 个人用，按需调用前端 / 后端 / 运营 / 法务专家
  • 国内 ToB / ToG 团队：需要快速搭建"小红书运营 + 抖音投放 + 飞书集成 + 合规审查"组合工作流
  • AI 编程工具重度用户：Claude Code / Cursor / Copilot / WorkBuddy 用户，希望给 AI 装上"专业大脑"
  • 高校学生 / 应试家庭：内置"高考志愿填报顾问"、"留学规划顾问"角色，2026 年高考季刚需
  • 内容创作者 / 跨境电商：需要持续输出小红书笔记 / 短视频脚本 / TikTok 投流策略
  • 多 Agent 研究者：相比 LangGraph / AutoGen / CrewAI，NEXUS 提供更轻量的中文生态方案

⚡ 快速上手

# 1. 安装 npm 包 npm install -g agency-agents-zh # 2. 克隆仓库（获取安装脚本） git clone --depth 1 https://github.com/jnMetaCode/agency-agents-zh.git cd agency-agents-zh # 3. 选择目标工具并安装（推荐 OpenClaw） ./scripts/convert.sh --tool openclaw ./scripts/install.sh --tool openclaw # 4. 重启 OpenClaw 网关 openclaw gateway restart # 5. 一句话调用专家 # 在 OpenClaw 中说： # "启动 marketing-xiaohongshu-operator 帮我写防晒霜种草文案"

其他工具（Claude Code / Cursor / Copilot / WorkBuddy）只需把 --tool openclaw 改为对应名称即可。
