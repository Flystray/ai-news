🚀 今日推荐：Graphify

Graphify-Labs/graphify 是一款将任意文件夹（代码、文档、论文、图片、视频）转化为可查询知识图谱的开源工具，灵感直接来自 Andrej Karpathy 的个人知识库工作流。它不只是复现了 Karpathy 的思路——更将"扁平 Markdown wiki"推进到了结构化 NetworkX 知识图谱，让 AI 编程助手从"逐文件搜索"进化为"图谱导航"。

一条 /graphify . 命令即可映射整个项目，支持 12+ AI 编程助手即插即用（Claude Code、Codex、Cursor、Gemini CLI、Aider、OpenClaw 等），30 秒安装上手。

🎯 一句话定位：不是向量索引，是真正的图——代码文件 AST 确定性解析（零 Token），文档论文 LLM 语义提取，合并为可遍历知识图谱。问"BM25 代码在哪"，直接命中节点而非返回一堆可能相关的片段。

🎯 核心功能

1. 双通道提取引擎

代码文件通过 tree-sitter AST 确定性解析（36+ 语言，零 Token 消耗），非代码文件（PDF、图片、视频）通过 LLM 语义提取。两条通道结果合并入同一 NetworkX 知识图谱，边标记为 EXTRACTED（源码直接提取）或 INFERRED（模型推断），审计轨迹清晰透明。

2. 社区发现与"上帝节点"识别

Leiden/Louvain 算法自动将节点聚类为功能模块社区，analyze.py 计算中心性指标，发现高连接度的"God Nodes"和跨社区的"惊喜关联"。无需人工维护索引，算法驱动的架构发现替代了逐文件阅读。

3. 12+ AI 编程助手即插即用

通过 graphify install 注册为 Skill，一条 /graphify 命令即可在 Claude Code、Codex、OpenCode、Cursor、Gemini CLI、Aider、OpenClaw、Kiro、Trae、Devin、Copilot、AMP 等 12+ 平台使用。每个平台有专属 skill 文件，内置"快速路径"（检测已有 graph.json 则跳过提取直接查询）、环境发现、安全阈值。

4. 增量更新与语义缓存

manifest.json 跟踪文件哈希，/graphify . update 仅处理变更部分。合并 PR 后秒级同步图谱，语义缓存确保已处理文件不重复消耗 Token。

5. 跨模态知识融合

add 命令可直接导入 arXiv 论文 URL，自动下载、语义提取并将论文概念节点加入图谱，建立"论文概念 → 代码实现"的映射路径。实测中一篇 A-MAC 论文的 5 个核心因子被自动对齐到项目代码的对应实现与权重参数。

6. 多格式输出

graph.html（交互可视化，点击节点/搜索/过滤）、GRAPH_REPORT.md（架构摘要+惊喜关联+推荐问题）、graph.json（完整图谱）、Obsidian 知识库导出、GraphML/Neo4j 格式支持。

7. path 路径追踪

/graphify path 追踪任意两节点之间的完整路径，每条边附带类型说明（语义关联、实现关系、调用关系），可用于论文复现验证、技术债务评估、代码审查和知识溯源。

💡 技术亮点

1. "不是向量索引，是真正的图"

核心哲学是拒绝 Embedding + 向量存储的 RAG 模式，转而构建可遍历的知识图谱。节点是具体实体（函数、类、概念），边是显式关系（调用、依赖、语义关联），查询通过图遍历而非近似匹配。回答的精确性不受向量相似度阈值影响——问"BM25 代码在哪个文件"，直接命中节点。

2. skillgen 幂等生成系统

12+ 平台的 skill 文件由 tools/skillgen/gen.py 从统一 fragment 模板渲染，保证跨平台行为一致且幂等（不含时间戳，不会产生无意义 diff）。--check 检测渲染漂移，--audit-coverage 确保原始 skill 的每个 heading 都在 split fragment 中保留。

3. 五层架构线性阶段门模型

File Detection → AST Extraction → Semantic LLM Extraction → Graph Assembly & Validation → Community Detection & Analysis。每层通过纯 Python dict 或 NetworkX 对象传递输出，模块边界清晰（detect.py、extract.py、llm、build.py、validate.py、cluster.py、analyze.py），便于独立测试和替换。

⚡ 快速上手

安装 CLI（30 秒）

uv tool install graphifyy    # 或: pipx install graphifyy
graphify install              # 注册到 AI 编程助手

在项目中生成知识图谱

/graphify .                  # 映射整个项目

常用命令

/graphify query "BM25代码在哪"    # 精准查询
/graphify . update                # 增量更新（PR 后）
/graphify add https://arxiv.org/abs/xxxx  # 导入论文
/graphify path                    # 路径追踪

输出文件在 graphify-out/：graph.html（交互可视化）、GRAPH_REPORT.md（架构摘要）、graph.json（完整图谱）。
