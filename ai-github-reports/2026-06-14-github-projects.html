📌 项目背景

全球铁路系统每年发生超过6,000 起站台安全事件，其中相当比例的自杀和盗窃行为在发生时，监控室的安保人员并未及时发现——传统 CCTV 系统的本质问题在于"记录而非预防"。事后回放录像确定"发生了什么"对已经发生的悲剧毫无意义。

更现实的问题是：对于绝大多数铁路运营商来说，"部署全新的 AI 安全系统"意味着数百万美元的前端摄像头更换和边缘服务器部署预算——这是不切实际的。

RailMind-AI 正是为解决这两个核心痛点而生的。它由 Team Accelerate 团队专为 FAR AWAY 2026 国际黑客松开发，核心理念是：用 AI 将现有被动 CCTV 基础设施转化为主动安全预警网络，零新硬件成本。项目采用 MIT 协议开源，将 YOLOv8 计算机视觉、BiLSTM 时序行为分析和 LangGraph 多智能体推理三者融合成一个可解释、可审计、隐私优先的铁路安全智能平台。

🚀 核心功能

1. 实时多路行为分析——零硬件改造

RailMind-AI 的设计前提是完全复用现有铁路 CCTV 网络。系统通过 RTSP 协议直接接入现有摄像头流，以 10FPS/路 的速率持续处理，支持 4 路并发（可扩展），在 Jetson Orin Nano（约 500 美元）边缘设备上即可达到实时处理性能。

2. 多层次风险行为检测

系统可识别三大类风险行为模式，通过 BiLSTM 模型对30 秒滑动窗口内的 7 维行为特征向量进行时序建模：

  • 自杀风险：长时间靠近站台边缘（>60s）、反复踱步、突然转向、蹲姿、社交退缩模式
  • 盗窃风险：持续近距离尾随（<0.5m）、重复近距离接触、高密度区域团伙协同行为
  • 安全威胁：高速移动 + 攻击性姿态 + 对抗性近距离接触

3. 可解释三智能体决策架构

基于 LangGraph 编排的三层智能体按序协作：

  1. 感知智能体：提取姿态特征 → LSTM 推理 → 判断是否需要干预
  2. 推理智能体：计算 0-100 分动态风险评分（融合 LSTM 置信度、站台距离、行为持续时间、人群密度等 6 个维度），可选调用 GPT-4/Claude 做语义化推理
  3. 干预智能体：梯度触发——40-69 分（控制台告警）→ 70-89 分（安保团队）→ 90-100 分（广播应急）

4. 持续学习闭环

系统内置每周自动重训练流水线：利用一线安保人员标注的误报反馈数据，持续优化 BiLSTM 模型。季度准确率可提升 2-3%。解决了 AI 安全系统"部署即老化"的行业通病。

5. 隐私原生设计

从架构层面排除人脸识别——所有行为分析仅基于肢体姿态和运动模式，追踪 ID 为会话级数字标识（会话结束即失效）。天然符合 GDPR、印度 PDPA 等全球主流数据隐私法规。

6. 前后端一体化管理控制台

React 19 + TanStack Router + Tailwind CSS 4 + shadcn/ui，包含实时监控（AI 标注叠加）、事件趋势分析（热力图）、告警全生命周期管理、摄像头状态管理等 4 个核心视图。

⚙️ 技术亮点

1. BiLSTM 时序行为建模——从"看图说话"到"理解行为演变"

传统视频安防系统大多在单帧上做目标检测和分类。RailMind-AI 的核心创新在于用 BiLSTM 对 7 维行为特征的 30 秒滑动窗口序列进行时序建模：

feature_vector = [
  edge_proximity_seconds,  # 距站台边缘0.5m内累计时间
  loitering_time,          # 单区域静止时长
  pacing_count,            # 往返运动周期数
  movement_speed,          # 10秒窗口平均速度（m/s）
  direction_changes,       # 每分钟方向反转次数
  following_distance,      # 与单个人持续接近距离（米）
  crowd_interactions       # 近距离接触的独立个体数
]

相比传统静态分类器，BiLSTM 的时序感知能力使误报率降低 60% 以上。准确率 >92%，误报率 <8%，推理延迟 <5ms（GPU）。

2. 边缘-云端混合架构——兼顾实时性与集中管理

原始视频完全在边缘处理，仅上传结构化行为特征和告警结果到云端——带宽节省 99.9%：

【边缘层】Jetson Orin Nano
CCTV流 → OpenCV → YOLOv8(12ms) → ByteTrack(3ms)
→ YOLOv8-Pose(15ms) → 特征提取 → BiLSTM(<5ms)
→ 仅上传JSON结果

【云端层】FastAPI + PostgreSQL
LangGraph 推理智能体(200ms) → 干预智能体 → WebSocket → React

3. 学术前沿 YOLOv8n 改进方案的工程落地

Frontiers in AI 期刊论文展示改进 YOLOv8n 在铁路检测中达到 mAP@0.5 90.2%，在 Jetson Nano 边缘设备上达到 28.6 FPS，模型体积仅 5.2MB。RailMind-AI 在实际部署中使用了这一改进路线。

⚡ 快速上手

# 1. 克隆仓库
git clone https://github.com/Abishek-kk/RailMind-AI.git
cd RailMind-AI

# 2. 后端配置
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

# 3. 训练 LSTM 模型
python -m app.lstm.cli train

# 4. 启动后端（API：http://localhost:8000）
python run.py

# 5. 启动前端（Dashboard：http://localhost:5173）
cd ../frontend
npm install
npm run dev

# 快速演示（无需摄像头）
cd backend
python scripts/demo_runner.py
