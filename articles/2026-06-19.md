# Google LangExtract：让LLM从非结构化文本中精准提取结构化数据，并精确溯源至原文

## 一、项目背景：非结构化文本的"宝藏"困境

企业最核心的数据往往以最"难用"的形式存在——冗长的临床病历、复杂的法律合同、海量的客服对话记录、不规则的业务报表。这些数据被称为**非结构化文本**，占据了全球数据的80%以上，却难以被计算机系统直接处理。

传统的解决方案有两种：一是基于规则的正则表达式匹配，维护成本高且在面对语序变体时脆弱不堪；二是训练专门的信息提取模型，需要大量标注数据和漫长的训练周期。

2025年7月，Google开源了**LangExtract**，给出了第三种答案：利用大语言模型（LLM）的语义理解能力，通过少量示例即可定义任意领域的提取任务，并且——这是最关键的创新——**每一个提取结果都能精确映射到原文中的字符位置**，生成可交互验证的可视化报告。

## 二、核心功能（7大功能深度解析）

### 1. 精确原文溯源（Precise Source Grounding）

这是LangExtract最具革命性的功能。传统LLM提取只给出结果，无法告知"这个结论从哪来的"。LangExtract通过内置的`WordAligner`组件，将模型输出的每个`extraction_text`精确映射到原文中的`CharInterval`字符区间，并对齐质量进行分级：

| 对齐状态 | 含义 | 应用场景 |
|---------|------|---------|
| `EXACT` | 字符级精确匹配 | 高可信度提取，可直接使用 |
| `FUZZY` | 模糊匹配（如标点差异） | 需人工复核 |
| `UNALIGNED` | 未对齐（模型"幻觉"） | 自动标记，提示用户检查 |

这一机制让LLM从"黑盒"变成了"透明盒"——每个结论都有据可查。

### 2. 声明式结构化输出

LangExtract采用**Few-shot提示范式**：用户只需提供任务描述（自然语言指令）和3-5个高质量示例，模型即可按照示例的结构输出结果。对于支持受控生成的模型（如Gemini），还能通过YAML Schema约束进一步保证输出格式的稳定性。

与需要复杂规则配置的传统IE（Information Extraction）工具相比，LangExtract的"提示词即配置"范式将任务定义时间从数天缩短至数十分钟。

### 3. 长文档并行处理

处理长文档时，LangExtract采用三级优化策略：

- **智能分块**：按`max_char_buffer`（默认1000字符）将文档分割为重叠片段，避免实体被切断
- **并行推理**：通过`ThreadPoolExecutor`实现多线程并发，默认`max_workers=20`，处理14万字符的《罗密欧与朱丽叶》全文仅需数分钟
- **多轮提取**：`extraction_passes`参数控制提取轮次（默认1次，建议长文档设为3次），每轮独立提取后合并，召回率可提升15-30%

### 4. 交互式HTML可视化

一行代码即可生成独立HTML文件：

```python
html_content = lx.visualize("results.jsonl")
```

生成的HTML文件中，原文与提取结果并排展示，鼠标悬停提取实体时自动高亮原文对应位置。这一功能在医疗、法律等需要审计追踪的场景中具有极高价值。

### 5. 多LLM后端支持（Provider插件系统）

LangExtract通过基于Python entry points的插件架构，支持接入多种LLM：

| Provider | 匹配模式 | 适用场景 |
|----------|---------|---------|
| Gemini | `^gemini-` | 默认推荐，成本与质量平衡 |
| OpenAI | `^(gpt-|o1-|o3-)` | 已有OpenAI API的用户 |
| Ollama | 模型名含`:` | 本地部署，隐私敏感场景 |
| 社区插件 | 自定义 | 任意兼容OpenAI API的模型 |

优先级机制：当`model_id`同时匹配多个Provider时，优先级数值高的Provider胜出。这一设计让LangExtract可以无缝切换云端与本地模型。

### 6. 跨领域零样本适配

无需微调模型，仅通过修改提示词和示例即可适配新领域。官方示例中涵盖了：
- **文学分析**：从《罗密欧与朱丽叶》提取人物、情感、关系
- **医疗信息**：从临床笔记提取药物名称、剂量、给药途径
- **放射报告**：RadExtract子项目专门处理放射学报告结构化

### 7. Vertex AI批量处理支持

针对大规模生产场景，LangExtract支持接入Google Vertex AI的批量推理API，成本可降低50-70%（与在线推理相比），适合每天处理数万份文档的企业场景。

## 三、技术亮点（3大架构创新）

### 亮点1：五层严格分层架构

LangExtract通过`import-linter`强制执行五层模块边界，防止架构退化：

```
应用层（extraction/io/visualization）
    ↑ 可导入所有下层
高层服务层（annotation/prompting/resolver/chunking）
    ↑ 可导入core和inference
服务层（inference — 推理协调）
    ↑ 可导入providers和core
提供者层（providers/* — 模型适配）
    ↑ 不可导入inference
核心层（core/* — 稳定抽象）
    ↑ 不依赖任何上层
```

这一架构带来的核心好处是：**Provider层可以独立演进**，社区可以无需修改核心代码即添加对新模型的支持。

### 亮点2：双坐标系溯源机制

溯源的技术实现是LangExtract最精巧的部分：

```
LLM输出extraction_text
    ↓
Tokenize（使用regex库的Unicode感知分词）
    ↓
与原文Token序列进行模糊/精确匹配
    ↓
映射到CharInterval（字符级位置）
    ↓
输出AlignmentStatus质量评级
```

特别值得注意的是，LangExtract会**自动检测并标记"示例泄漏"**——如果模型在提取结果中复现了示例中的内容（而非输入文本中的内容），会将对应结果的`char_interval`设为`None`，提醒用户检查提示词对齐质量。

### 亮点3：可控生成与格式约束

对于Gemini等支持受控生成的模型，LangExtract通过`FormatHandler`（基于PyYAML）将输出约束为符合YAML Schema的结构化文本，解析失败率低于0.1%（官方测试数据）。对于不支持受控生成的模型（如早期Ollama版本），则通过后处理解析兜底，保证输出的可用性。

## 五、快速上手

### 安装

```bash
# 基础安装
pip install langextract

# 包含全部可选依赖（推荐）
pip install "langextract[full]"

# 支持OpenAI后端
pip install "langextract[openai]"
```

### 最小示例（中文场景）

```python
import langextract as lx
import textwrap

# 定义提取任务
prompt = textwrap.dedent("""\
从文本中提取人物、情感和关系。
使用原文精确文本，不要改写。
""")

examples = [
    lx.data.ExampleData(
        text="小王轻轻叹气，决定给小李写一封信。",
        extractions=[
            lx.data.Extraction(
                extraction_class="人物",
                extraction_text="小王",
                attributes={"情感状态": "叹息、犹豫"}
            ),
            lx.data.Extraction(
                extraction_class="关系",
                extraction_text="给小李写一封信",
                attributes={"类型": "通信意向"}
            ),
        ]
    )
]

# 执行提取
result = lx.extract(
    text_or_documents="小李收到信后，脸上露出了久违的笑容。",
    prompt_description=prompt,
    examples=examples,
    model_id="gemini-2.5-flash",
)

# 生成可视化
lx.io.save_annotated_documents([result], output_name="result.jsonl", output_dir=".")
html = lx.visualize("result.jsonl")
with open("visualization.html", "w", encoding="utf-8") as f:
    f.write(html)
```

## 七、总结

LangExtract代表了LLM时代信息提取的新范式：**可追溯、可验证、低门槛**。它将LLM的"语义理解"能力与传统NLP的"精确对齐"能力有机结合，填补了现有工具生态的重要空白。

对于需要在生产环境中使用LLM进行信息提取的团队，LangExtract提供的溯源机制和可视化能力，是满足合规审计要求的关键支撑。而其插件化的Provider架构，也为企业在多云/混合部署场景下提供了充分的灵活性。
