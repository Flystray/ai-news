作者是 TypeScript 社区知名教育者（Total TypeScript 课程创始人），把 13 年工程经验沉淀的 22 个 Claude Code 技能全部开源。这是真实工程项目里磨出来的工具，不是教程里的演示玩具。

🎯 是什么？解决什么问题？

当大多数人还在用 Claude Code 写"氛围代码"时，Matt Pocock 已经把它整合进了完整的工程工作流。

这个仓库包含 22 个精心设计的「技能」，每个技能都是一个可复用的 AI 工作流单元，直接来自作者的 .claude 目录（Claude Code 的本地配置）。覆盖从需求分析、PRD 生成、Issue 拆解，到 TDD 开发、架构重构、代码质量保障的完整研发链路。

如果你把 Claude Code 当成"聊天机器人"在用，你只用到了它 10% 的价值。这 22 个技能展示了剩下 90% 的正确打开方式。

📦 22 个技能全览

📋 规划与设计（4个）
to-prd
将对话上下文直接合成为 PRD，自动提交为 GitHub Issue
to-issues
将 PRD 按垂直切片拆分为多个独立可执行的 GitHub Issue
grill-me
深度追问方案，直到所有决策分支全部落定
design-an-interface
并行子代理生成多个差异化接口方案，让 AI 自己 PK
⚙️ 开发类（5个）
tdd
标准 TDD 循环：红→绿→重构，按垂直切片逐步实现
triage-issue
遍历代码库定位 bug 根因，生成含 TDD 修复方案的 Issue
improve-codebase-architecture
结合 ADR 文档自动发现架构优化点
request-refactor-plan
访谈式生成含细粒度 commit 的详细重构计划
🔧 工具链（2个）
setup-pre-commit
一键配置 Husky + lint-staged + Prettier + 类型检查
git-guardrails-claude-code
拦截 push/reset --hard/clean 等危险 git 命令，强制确认
✍️ 写作与知识（4个）
write-a-skill
创建新技能（规范结构 + 渐进披露设计）
edit-article
重构文章章节、提升清晰度、精简措辞
ubiquitous-language
从对话提取 DDD 统一语言词汇表
obsidian-vault
搜索、创建、管理 Obsidian 笔记（含维基链接）

🚀 怎么用？

安装某个技能只需一行命令（需要先安装 Claude Code）：

# 安装 to-prd 技能（需求分析 → PRD → GitHub Issue）
npx skills@latest add mattpocock/skills/to-prd

# 安装 tdd 技能（测试驱动开发）
npx skills@latest add mattpocock/skills/tdd

# 安装 git-guardrails（强烈推荐！防止代理误删代码）
npx skills@latest add mattpocock/skills/git-guardrails-claude-code

# 安装 design-an-interface（并行接口方案生成）
npx skills@latest add mattpocock/skills/design-an-interface

安装后在 Claude Code 对话中直接输入技能名称即可调用。订阅 newsletter 获取新技能更新：aihero.dev/s/skills-newsletter
