# Argus-AI：生产级 LLM 可观测性格栅，用 3 行代码守护 AI 应用质量

**2026-05-15** | ⭐ **项目亮点**：G-ARVIS 六维度评分系统 · Sub-5ms 评估延迟 · 无外部 API 依赖 · Apache-2.0 开源

---

## 项目背景

当 LLM 应用进入生产环境，一个严峻的问题浮出水面：**模型更新、Prompt 漂移、上下文溢出、成本失控**——这些问题往往在造成实际损失后才被发现。

传统 APM 工具（Datadog、New Relic）擅长追踪延迟和错误率，但**无法检测**：模型更新后幻觉率上升了 12%、Prompt 在上下文超过 80K tokens 时悄然失去事实依据。

Argus-AI 正是为解决这一痛点而生。它是 Ambharii Labs 推出的生产级 LLM 可观测性格栅，通过 G-ARVIS 六维度评分引擎，让每一个 LLM 响应都获得可量化的质量分数。

---

## 核心功能

### 1. G-ARVIS 六维度质量评分

Argus-AI 实现了业界最全面的 LLM 响应评分体系，六个维度相互正交、覆盖全面：

| 维度 | 全称 | 评估内容 | 典型应用场景 |
|:----:|------|----------|--------------|
| **G** | Groundedness | 响应是否基于提供的上下文，幻觉检测 | RAG、文档 QA、知识检索 |
| **A** | Accuracy | 与标准答案一致性、逻辑完整性、数值验证 | 问答系统、摘要生成 |
| **R** | Reliability | 格式一致性、完整性检测、SLA 合规 | 结构化输出、API 响应 |
| **V** | Variance | 输出确定性、置信度信号、词汇多样性 | 检测 Prompt 漂移 |
| **I** | Inference Cost | Token 效率、成本/价值比、延迟比 | 成本优化、预算控制 |
| **S** | Safety | PII 泄露、毒性检测、提示注入防护 | 医疗、金融、用户数据 |

### 2. Agentic 工作流专项评估

针对自主代理（Agent）场景，Argus-AI 提供三项核心指标：

| 指标 | 全称 | 计算公式 | 生产阈值 |
|------|------|----------|----------|
| **ASF** | Agent Stability Factor | `Completion rate × Failure resilience × Retry consistency` | ≥ 0.85 |
| **ERR** | Error Recovery Rate | `Recovered steps / Failed steps` | ≥ 0.70 |
| **CPCS** | Cost Per Completed Step | `Total spend / Successfully completed steps` | ≤ $0.10/步 |

### 3. 阈值监控与智能告警

- **滑动窗口违规检测**：自动识别质量下滑趋势
- **多级严重性分类**：CRITICAL / HIGH / MEDIUM / LOW
- **自定义回调钩子**：PagerDuty、Slack、Webhook 无缝集成
- **多平台可观测性导出**：Prometheus (Gauges/HHistograms)、OpenTelemetry（Grafana、Datadog、New Relic 兼容）

### 4. 零代码接入的 Provider 包装器

Argus-AI 提供 `InstrumentedAnthropic` 和 `InstrumentedOpenAI` 客户端，自动在每次 API 调用时进行评分：

## 技术亮点

### 1. 启发式评分架构：无外部 API 调用

这是 Argus-AI 与众不同的核心设计。大多数 LLM 评估工具依赖 GPT-4 或 Claude 进行「LLM-as-judge」评估，每次调用耗时 1-5 秒、成本 $0.01-0.05。

Argus-AI 采用**纯启发式算法**，无需调用任何外部 LLM API：
- 评分延迟：**< 5ms**（比 LLM-as-judge 快 200-1000 倍）
- 零网络依赖：可嵌入生产热路径（hot path）
- 零额外成本：无 Token 消耗

### 2. 开放核心架构

Argus-AI 采用 **Open Core** 模式，Apache-2.0 开源部分与商业版形成互补：

| 开源组件 (Apache-2.0) | 商业增强 (ARGUS Platform) |
|------------------------|---------------------------|
| G-ARVIS 复合评分器 | 编排代理（Orchestrator） |
| 6 个独立维度评分器 | 自动提示优化器 |
| ASF / ERR / CPCS 指标 | 闭环自修复管道 |
| 3 行 Python SDK | LLM-as-judge 评估 |
| 阈值监控与告警 | 多轮方差分析 |
| Prometheus / OTEL 导出 | Dashboard UI |
| Anthropic / OpenAI 包装器 | SOC2 / HIPAA 合规 |

### 3. 生产级质量保证

- **84 个测试用例**，覆盖率 **93%**
- **mypy strict mode** 类型检查
- **Beta 版本** (v0.1.0)，已发布至 PyPI（2026-03-28）

## 快速上手

### 安装（3 秒）

```bash
pip install argus-ai
# 可选依赖
pip install "argus-ai[anthropic]"  # Claude 支持
pip install "argus-ai[prometheus]" # 指标导出
```

### 基础使用（3 行代码）

```python
import argus_ai

argus = argus_ai.init(profile="enterprise")

result = argus.evaluate(
    prompt="What are the Q3 revenue trends?",
    response="Revenue increased 12% YoY to $4.2B.",
    context="Q3 financial report: 12% YoY growth.",
    model_name="claude-sonnet-4",
    latency_ms=1200.0,
)
```
