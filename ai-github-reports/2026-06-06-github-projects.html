9router

一站式 AI 编程路由器 — 永不掉线，节省 20-40% Token

2026 年，AI 编程工具已成为开发者日常工作中不可或缺的一部分。但订阅配额浪费、速率限制打断工作流、工具输出消耗大量 Token、多工具多账号管理混乱等问题日益突出。9router 就是这个痛点的一站式解决方案——一个跑在本地的 AI 智能路由中间件，让所有 AI 编程工具接入同一个统一端点，自动在订阅/低价/免费提供商之间无缝切换，永不中断编码工作流。

🚀 核心功能

  • 三层级自动降级容错：请求失败时自动按「订阅层级 → 低价层级 → 免费层级」顺序切换。例如：Claude Code 订阅配额用尽后，自动切换到 GLM（¥0.6/1M）→ MiniMax（¥0.2/1M）→ Kiro AI 免费 Claude → OpenCode Free，全程零停机时间。
  • RTK Token 节省器（节省 20-40%）：内置的 RTK 模块自动识别和压缩 tool_result 内容（如 git diff 输出、目录列表等），实测可减少单次请求 20-40% 的 Token 消耗，直接降低 API 成本。
  • MITM 透明代理：支持拦截硬编码端点的 AI 工具流量（如 GitHub Copilot、Claude Code），无需修改工具配置即可接入 9router 的路由能力。支持 Linux NSS DB 证书注入，适配 Chrome、Firefox、Snap 版浏览器。
  • 多账号负载均衡：支持单服务商配置多个账号，自动轮询账号、处理配额限制和速率限制。例如同时配置 3 个 Claude Code 订阅账号，自动在它们之间轮询。
  • 40+ 提供商、100+ 模型统一接入：覆盖 OpenAI、Anthropic、Google Gemini、AWS Bedrock、Azure AI、智谱 GLM、MiniMax、阿里云百炼、腾讯混元、DeepSeek、Qwen 等。
  • 可视化 Web 仪表盘：基于 React 19 开发，运行在 http://localhost:20128，支持提供商管理、连接测试、用量监控、配置修改、实时请求日志查看。
  • MCP 协议桥接：支持 Model Context Protocol 桥接，适配下一代 AI 工具协议，可将 MCP 服务器也接入统一路由体系。

⚙️ 技术亮点

  • 三层 SQLite 容错存储架构：按环境自动降级——优先使用 better-sqlite3，其次使用 Node.js 22.5+ 内置的 node:sqlite，最后降级为 WASM 版的 sql.js。全环境兼容，数据不丢失。这是从低性能的 lowdb JSON 存储升级而来，是生产级可靠性的重要保障。
  • OAuth 令牌刷新防竞争机制：令牌刷新时采用飞行中请求缓存机制，避免多个并发请求同时触发令牌刷新，解决令牌刷新冲突问题。这是生产级 AI 网关必须处理但很多开源项目忽略的边界条件。
  • 用量配额实时查询系统：主动从 Gemini、GLM、MiniMax 等提供商的 API 查询实时用量和剩余配额，在配额耗尽前主动切换，避免超额调用触发限流。这是 9router 能实现「永不停歇」的关键技术之一。
  • 模型组合（Combo）支持：支持将多个模型配置为组合序列，支持 Sticky 轮询策略，保障多轮对话的一致性，适配复杂业务场景。
  • Tailscale 隧道适配：网络层支持 proxyAwareFetch 和 Tailscale TUN 模式，保障复杂网络环境下的服务稳定性。

👥 适用人群

  • 高频使用 AI 编码工具的开发者：Cursor、Claude Code、Cline、GitHub Copilot 的重度用户，希望降低成本、提升稳定性
  • 多 AI 服务商用户：同时使用多个 AI 模型，需要统一管理、降低成本
  • AI 应用开发者：需要开发兼容多模型的应用，不想重复适配不同厂商接口规范
  • 个人/小团队：需要低成本搭建自己的 AI 网关，避免单一服务商故障导致服务中断
  • 隐私敏感用户：希望使用本地模型（Ollama）+ 云端模型混合部署，数据不出本地网络

⚡ 快速上手

方式一：npm 全局安装（最简单）

# 全局安装 npm install -g 9router # 启动控制台（会自动打开 http://localhost:20128） 9router

方式二：Docker 部署

docker run -d \ --name 9router \ -p 20128:20128 \ -v ~/9router-data:/data \ 9router/9router:latest

连接免费提供商（无需注册）：打开控制台 → 提供商 → 连接 Kiro AI（免费 Claude 无限量）或 OpenCode Free → 完成！

在 Claude Code / Cursor 中使用：

Endpoint: http://localhost:20128/v1 API Key: 任意字符串（9router 不验证）
