项目背景

2026 年，AI 编程 Agent 已成为开发者日常工具。但它们都有一个共同的痛点：上下文窗口是临时的。每次新会话开始，Agent 就忘记了一切。各 Agent 提供的"记忆"方案（Claude Code 的 MEMORY.md、Cursor 的 Notepad）本质上是便签式存储，既不可搜索，也无法跨工具共享。

随着观测量增长，MEMORY.md 的 Token 消耗线性膨胀：积累到 1,000 条时需要 5 万 Token 且只覆盖 20% 的历史；到 5,000 条时需要 25 万 Token，可达率仅剩 4%。

AgentMemory 将 Karpathy 的 LLM Wiki 模式工程化，加入置信度评分、生命周期管理、知识图谱和混合搜索，打造一个真正可搜索、可检索、可跨 Agent 共享的持久记忆系统。目前获得 20,800+ Stars，在 Trendshift 进入第 19 位，获 AlphaSignal（18 万订阅）和 Linux Foundation 支持的 AAIF 关注。

三层运行时架构

整个运行时是单进程 Node.js 应用，零外部数据库依赖（无 Redis、Kafka、Postgres、Qdrant、Neo4j），状态以 JSON 持久化到本地磁盘：

01
HOOKS 钩子层 12 个自动捕获钩子接入每个编码 Agent，每次工具调用、每个提示词、每次停止都被压缩为观测记录。无需任何胶水代码，安装即用。
02
RECALL 召回层 三流检索（BM25 + 向量 + 知识图谱），设备端重排序，P50 延迟低于 20ms。
03
CONSOLIDATE 整合层 每小时扫描，将原始观测压缩为语义记忆，合并重复项，衰减过期数据，每次删除生成审计记录。
