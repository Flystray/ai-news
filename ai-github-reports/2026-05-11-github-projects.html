Get Shit Done (GSD) - AI 编程的工程化框架

项目地址：github.com/gsd-build/get-shit-done

技术栈： JavaScriptMeta-PromptingContext EngineeringMIT License

一句话介绍：一个轻量但强大的元提示、上下文工程与规格驱动开发系统，解决 AI 辅助编程中的"上下文腐烂"难题。

📖项目背景

当你用 Claude Code 或 Cursor 开发了半小时后，是否发现 AI 的回答越来越"笨"？这不是你的错觉——这是 上下文腐烂（Context Rot），是当下所有 AI 编程助手面临的核心痛点。

AI 模型的上下文窗口（如 Claude 的 200K token）在长时间对话中逐渐被填满，历史信息、代码片段、调试日志不断累积，导致模型"记忆过载"，输出质量显著下降。更糟糕的是，传统 AI 编程缺乏可追踪、可验证的工程流程，往往变成无结构的"氛围编码（Vibecoding）"——看起来很酷，但产出难以维护。

Get Shit Done（GSD） 应运而生。这是一个元提示（meta-prompting）、上下文工程（context engineering）和规格驱动开发（spec-driven development）系统，将 AI 编程从"碰运气"升级为可验证的工程化流程。项目由 TÂCHES 团队开发，2025 年 12 月发布，仅 5 个月便获得 6.1 万 Star，成为 AI 编程工具链中最受关注的项目之一。

⚡核心功能

1. 薄编排器模式（Thin Orchestrator Pattern）

GSD 的核心架构创新。它使用精简的协调器生成专用代理（agent），每个代理拥有全新的 200K+ token 上下文，从根本上避免单个代理累积过多实现细节导致的质量退化。

2. 阶段化工作流（Discuss → Plan → Execute → Verify）

严格的四阶段生命周期，确保每一步都可验证：

  • Discuss：与用户讨论需求和目标
  • Plan：gsd-planner 创建详细执行计划，gsd-plan-checker 验证计划质量
  • Execute：gsd-executor 按计划执行，支持并行执行（Waves）、检查点（Checkpoints）
  • Verify：gsd-verifier 通过目标反向分析验证完成度

3. 多运行时支持（15+ AI 工具）

单一代码库通过转换引擎适配 15+ AI 运行时：Claude Code、OpenCode、Gemini CLI、Codex、GitHub Copilot、Cursor、Windsurf、Antigravity、Trae、Qwen Code、Cline、Augment 等。自动检测环境并输出对应格式。

4. 文件化状态管理

所有项目状态持久化在 .planning/ 目录，使用结构化 Markdown + YAML frontmatter：

  • PLAN.md：阶段计划（任务列表、目标、验证标准）
  • ROADMAP.md：项目路线图
  • STATE.md：当前项目状态
  • VERIFICATION.md：验证结果记录

人类可读，机器可处理，支持 Git 版本控制。

5. 原子化 Git 提交

每个任务一次提交，标准化消息格式，创建完全可追溯的开发历史。与传统的"大杂烩提交"说再见。

6. Nyquist 验证（需求可证伪性）

在研究阶段即进行测试覆盖率映射，确保每个需求都有对应的验证手段。这是 GSD 对软件工程理论的创新贡献——将需求可证伪性引入 AI 编程流程。

7. 命名空间元技能（v1.41+）

通过分层路由机制，将冷启动开销从 ~2,150 token 降至 ~120 token（降低约 94%）。6 个命名空间元技能实现两阶段加载，极致优化 token 效率。

💡技术亮点

亮点 1：上下文工程（Context Engineering）

GSD 将"上下文管理"作为一等公民：

  • 受控上下文预算：精确管理每个代理的上下文使用量
  • 提示精简机制：自动减少冗余信息，防止质量退化
  • 新鲜上下文策略：每次任务由新代理执行，避免历史累积

这三者结合，使 GSD 能有效维持 AI 输出质量，即使项目持续数天。

亮点 2：无头 SDK（Headless SDK）

@gsd-build/sdk 支持自主项目执行，无需人工干预。结合 gsd-tools.cjs 集中式 CLI 工具，可实现 CI/CD 流水线中的全自动 AI 开发。

亮点 3：Brownfield 项目集成

GSD 不仅支持新项目（Greenfield），还支持已有项目的 AI 集成（Brownfield）。通过代码库映射工具（gsd-tools map-codebase）和依赖图生成（gsd-tools graphify），AI 能快速理解遗留代码。

🚀快速上手

安装（30 秒完成）

npx get-shit-done-cc@latest

安装脚本自动检测你的 AI 运行时环境（Claude Code、Cursor 等），并将 GSD 命令注入对应工具。

最小化安装（v1.41+）

npx get-shit-done-cc@latest --minimal

仅安装核心技能，进一步减少系统提示开销（适合对 token 预算敏感的场景）。

第一个项目

# 在 AI 编程工具中输入
/gsd-new-project my-ai-app

GSD 将引导你完成需求讨论、计划制定、执行和验证的完整流程。
