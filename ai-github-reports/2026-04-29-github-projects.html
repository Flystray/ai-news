Graphify

将任意代码库、文档、论文、图片和视频转化为可查询的知识图谱，为 AI 编程助手提供结构化代码理解，实现 71.5 倍 Token 压缩率

claude-code knowledge-graph graphrag tree-sitter ai-coding

💡 灵感来源：AI 教育先驱 Andrej Karpathy 维护一个 /raw 文件夹，随手把论文、截图、笔记丢进去。每次需要回顾主题时，要把整个文件夹喂给 LLM——浪费大量 Token。Graphify 就是这个痛点的答案：把原始文件变成结构化知识图谱，71.5 倍压缩，跨会话持久化。

2026 年 4 月初发布，仅 26 天 GitHub Stars 飙升至 37.5k。Graphify 是一款多模态知识图谱构建工具，专为 Claude Code、Codex、Cursor 等 AI 编程助手设计。通过 Tree-sitter 静态分析提取代码结构，结合 LLM 语义提取文档和图片内容，使用 Leiden 算法进行零 embedding 聚类，最终生成可查询的知识图谱。无需向量数据库、无需外部服务，完全本地运行。

🚀 核心功能

  • 多模态知识提取 — 支持 25 种编程语言的 AST 解析（Python、TypeScript、Go、Rust、Java 等），同时支持 Markdown、PDF、图片（白板照片、架构图）、音视频文件（Whisper 本地转录）。所有内容统一进入同一张知识图谱
  • 三种标准产物 — graph.html（基于 vis.js 的可交互图谱，浏览器中点击节点、搜索、按社区过滤）、GRAPH_REPORT.md（结构化分析报告：核心节点、意外连接、建议问题）、graph.json（持久化图谱数据，支持 Neo4j 导出）
  • 全平台集成 — Claude Code、OpenAI Codex、Cursor、Gemini CLI、GitHub Copilot、Aider、OpenClaw 等 10+ 个工具的 /graphify 命令直接可用。一条命令完成安装配置，支持 MCP Server 模式
  • 零 embedding 聚类 — 使用 Leiden 社区发现算法基于图拓扑结构划分社区，不需要向量数据库、不需要 embedding 模型，完全本地运行
  • 增量更新与实时监控 — SHA256 哈希缓存机制，只重新解析变更部分。--watch 后台监控模式、Git Hooks 自动更新
  • 安全设计 — 严格输入验证、SSRF/注入/XSS 防护、Cypher 注入防御。零遥测数据收集，仅向已配置的 AI 模型 API 发送语义内容（不发送原始源码）

⚙️ 技术亮点

7 阶段模块化流水线：

  1. detect — 文件检测，支持 .graphifyignore 排除规则
  2. extract — 代码用 Tree-sitter 提取 AST（函数、类、导入、调用、docstring）；文档/图片用 Claude Vision 提取语义；音视频用 Whisper 转录后再提取
  3. build — 合并为 NetworkX 图，节点=概念/函数/类，边=调用/继承/引用
  4. cluster — Leiden 算法基于图拓扑结构划分社区，无需向量嵌入
  5. analyze — 识别 God Nodes（核心组件）、Surprise Connections（意外跨域连接）
  6. report — 从 # NOTE: # WHY: 注释中提取设计动机，生成 GRAPH_REPORT.md
  7. export — HTML 交互图谱 + JSON + Obsidian 兼容格式 + Neo4j Cypher

三级置信度体系（降低 AI 幻觉风险）：

级别含义置信度
EXTRACTED源码中直接存在的确定关系1.0
INFERREDLLM 合理推断的潜在关系0.0~1.0
AMBIGUOUS不确定的关系，需人工审核—

71.5 倍 Token 压缩 — 在 Karpathy 风格混合语料库（3 个 GPT 框架 + 5 篇论文 + 4 张图，~92k 词）上，传统方式查询消耗 ~123k tokens，Graphify 子图查询仅 ~1.7k tokens。
