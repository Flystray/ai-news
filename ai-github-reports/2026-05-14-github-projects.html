腾讯开源的企业级知识管理框架，将原始文档转换为可查询 RAG、自主推理 Agent 和自维护 Wiki 的一体化解决方案。

🚀 核心功能

  • 三大交互模式：RAG 快速问答（日常查询）、ReAct Agent（复杂推理）、Wiki Mode（自动生成知识库）
  • 多格式文档解析：支持 PDF、Word、Excel、图片（VLM）、音频（ASR）等 15+ 格式
  • 自适应三层分块：标题感知 / 启发式 / 递归三种策略，文档自动路由
  • MCP 工具集成：支持 MCP Server 扩展，敏感操作可配置人机审批（Human-in-the-Loop）
  • 多源数据同步：飞书、Notion、语雀等外部平台自动同步
  • 多租户隔离：企业级权限管理，支持按知识库独立配置索引策略
  • 全渠道推送：企业微信、飞书、Slack、Telegram 等 IM 渠道直接问答

⚙️ 技术亮点

  • Go 语言后端：goroutine 轻量级协程，高并发低内存占用，适合企业级高负载场景
  • 依赖注入架构：使用 uber-go/dig 容器，LLM/向量库/存储均可热插拔替换
  • Wiki Mode 独家功能：从原始文档自动生成 Markdown 知识库 + Neo4j 交互式知识图谱
  • Langfuse 全链路追踪：Agent 运行、Token 使用、任务流水线可视化监控
  • 多向量引擎支持：pgvector、Qdrant、Milvus、Weaviate 可自由切换
  • 20+ 模型厂商：OpenAI、DeepSeek、Qwen、智谱、混元、Gemini、Ollama 等全面兼容

👥 适用人群

  • 企业知识管理团队：构建内部知识库、文档问答系统
  • RAG 应用开发者：快速搭建企业级 RAG 系统，无需从零开发
  • AI 应用集成商：为客户提供私有化部署的智能知识服务
  • 技术团队负责人：评估开源知识管理方案，选择高性价比技术栈
