## 📌 项目背景

在数字化转型浪潮中，企业知识管理面临两大核心挑战：**信息孤岛**与**检索效率低下**。传统关键词搜索无法理解语义，而通用 LLM 应用又缺乏对专业文档的深度理解能力。

**WeKnora（维娜拉）** 是腾讯于2025年7月开源的企业级知识管理框架，围绕三大核心能力构建：

1. **RAG 快速问答**：适合日常知识查询的检索增强生成
2. **ReAct Agent 智能推理**：自主编排知识检索、MCP 工具与网络搜索，完成复杂多步任务
3. **Wiki 模式**：让 Agent 从原始文档中自治生成相互链接的 Markdown 知识库与可视化知识图谱

> 根据腾讯官方数据，WeKnora v0.5.2 版本支持万级文档知识库规模，Wiki 入库通过通用任务队列 + 死信队列保障可靠性。

## ⚙️ 技术亮点

### 1. Go 语言后端：高性能与高并发

WeKnora 后端采用 **Go 语言**开发，相比 Python 框架具有显著优势：

| 指标 | Go 优势 | Python 对比 |
|------|--------|-----------|
| **并发处理** | goroutine 轻量级协程，并发处理能力极强 | GIL 限制，多线程开销大 |
| **内存效率** | 内存占用低，适合长时间运行服务 | 内存占用较高 |
| **启动速度** | 二进制编译，启动快速 | 解释执行，启动较慢 |
| **部署复杂度** | 单二进制文件，依赖少 | 需要 Python 环境 |

> 这使得 WeKnora 在高并发场景（如企业级知识库问答）下表现出色，同时保持低运维成本。

### 2. 依赖注入架构：模块化可扩展

```
internal/
├── container/container.go    # 依赖注入容器（uber-go/dig）
├── service/                 # 业务服务层
├── repository/              # 数据访问层
├── router/                 # API 路由
```

使用 `uber-go/dig` 容器管理服务、仓库和处理器，实现了**解耦组件设计**：

- LLM 模型可热插拔（OpenAI ↔ DeepSeek ↔ Qwen）
- 向量数据库可切换（pgvector ↔ Qdrant ↔ Milvus）
- 存储后端可替换（本地 ↔ 云存储）

### 3. Wiki Mode：知识自动化沉淀

这是 WeKnora 区别于其他 RAG 框架的核心创新。传统 RAG 只能回答问题，而 **Wiki Mode** 能：

- 从原始文档自动生成**结构化 Markdown 知识库**
- 构建**交互式知识图谱**（基于 Neo4j 图数据库）
- 支持**万级文档规模**入库（任务队列 + 死信队列保障可靠性）
- 提供**页面链接图 API** + 交互式探索 UI

> 简单来说：只要上传原始文档，WeKnora 能自动生成一个可浏览、可查询、可维护的企业知识库。

## ⚡ 快速上手

### 环境要求

- Docker & Docker Compose
- 4核 CPU / 8GB RAM（最低）
- PostgreSQL + Redis（Docker 内置）

### 一键部署

```bash
# 克隆项目
git clone https://github.com/Tencent/WeKnora.git
cd WeKnora

# 启动所有服务
docker-compose up -d

# 访问 Web UI
open http://localhost:3000
```

### 初始化配置

1. 访问 `http://localhost:3000` 创建管理员账户
2. 配置 LLM API（推荐 OpenAI / DeepSeek / Qwen）
3. 配置向量数据库（推荐 pgvector 起步）
4. 创建知识库，上传文档
