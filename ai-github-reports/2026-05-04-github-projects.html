🎯 项目背景

2026年4月17日，Anthropic 发布 Claude Design——对话驱动的 AI 设计工具，输入一句话，25分钟内交付可直接使用的原型稿、演示文稿或营销素材。消息一出，Figma 股价应声下跌 4.6%。

然而 Claude Design 保持了所有"传统美德"：闭源、付费、只跑云端、绑定 Anthropic 模型。整个社区的心情用一个字形容：憋屈。

Open Design（OD） 正是对这种憋屈的精准回应。nexu-io 团队没有从头造一个 AI 设计工具，而是做了一件更聪明的事——把你电脑上已有的最强 coding agent 直接变成设计引擎。同一套循环、同一种 artifact-first 心智模型，但没有任何锁定。

🛠️ 技术栈

TypeScript Next.js 16 React 18 Express SQLite pnpm

架构亮点：三层架构——浏览器层（Next.js 16）通过 SSE 与本地 Daemon（Express + SQLite）通信，Daemon 在磁盘上 spawn 用户已安装的 Agent CLI，Agent 拥有真实文件系统访问能力。

💡 技术亮点（4 大架构创新）

亮点 1：委托模式——不造 Agent，用适配器串联现成 Agent

OD 最大的架构创新。10 个不同协议、不同通信格式的 Agent CLI，通过自定义适配器全部串联成一个设计工作流。最强大的 coding agent 已经装在千千万万台电脑上了，OD 要做的只是给它接一个设计界面。

亮点 2：三段式本地架构

浏览器层（Next.js 16 SSE） ↔ Daemon 层（Express + SQLite） ↔ Agent 层（用户本地 CLI）。每一层职责清晰，扩展性强。

亮点 3：22,000+ 种 Skill × Design × Agent 组合

31 Skills × 72 Design Systems × 10 Agent CLI，每套组合都有确定性输出，不需要每次都从零调 prompt。

亮点 4：Skill as Infrastructure 新范式

未来 AI 应用的核心竞争力不再是"哪个模型最强"，而是"你的 Agent 装了多少 Skill 包"。Skill 是可复用、可组合、可分享的技能单元。

🚀 快速上手（3 步跑起来）

环境要求：Node.js ~24，pnpm 10.33.x，Git，至少一个 Agent CLI（Claude Code / Codex / Cursor 等）

# 第一步：克隆仓库 git clone https://github.com/nexu-io/open-design.git cd open-design # 第二步：安装依赖 corepack enable pnpm install # 第三步：启动服务 pnpm tools-dev run web # 浏览器访问 http://localhost:3000 # BYOK 模式（无 CLI 时）： export ANTHROPIC_BASE_URL="https://api.anthropic.com" export ANTHROPIC_API_KEY="sk-ant-xxxxx" pnpm tools-dev run web

🏆 为什么 4 天狂揽 1.5 万星？

本质上是一次开源社区对商业封闭产品的精准反击。 Claude Design 出圈后，Anthropic 把一个好东西锁在围墙里——闭源、付费、云端、绑定模型。OD 团队没有选择抱怨，而是用 6 天时间把它"拆了出来"。

更重要的是，它验证了一个新的 AI 应用构建范式：Skill as Infrastructure。未来 AI 应用的核心竞争力，不再是"哪个模型最强"，而是"你的 Agent 装了多少 Skill 包"。开源的力量，从来都不该被低估。
