📌 项目背景

AI 编程助手（Claude Code、Cursor、Copilot 等）理解代码时有个致命短板：只能逐文件搜索。想知道「谁调用了 processOrder」，就得先 grep 搜一遍，再挨个文件读，再 grep 再读……5 次结构查询能吃掉 412,000 个 Token，而结果还常常遗漏跨文件的类型推断和接口实现关系。

在 $3-15/M Token 的定价下，探索成本是真金白银；在「中间遗忘」效应下，信息噪声是真真切切的答案质量下降。

codebase-memory-mcp 提出了根本性解法：把整个代码库索引为一张持久化的 SQLite 知识图谱，Agent 直接对图谱做结构查询——亚毫秒响应、99.2% Token 缩减、83% 答案准确率（31 个真实代码库评测，arXiv:2603.27277）。整个系统编译为单个纯 C 静态二进制文件，零运行时依赖，所有数据本地处理，代码不出机器。

🚀 核心功能

⚡ 极速索引

Linux 内核（28M LOC / 75K 文件）完整索引 3 分钟 → 481万节点 + 772万边。Django 约 6 秒。内存优先策略：LZ4 + 内存版 SQLite + Aho-Corasick。

🧠 双层语义解析

第一层 Tree-sitter 158 语言语法解析；第二层 Hybrid LSP 9 语言家族类型推断（Python/TS/Go/Rust 等）——解析泛型、继承、标准库追踪。

🔗 丰富边类型

CALLS/ASYNC_CALLS、HTTP_CALLS（跨服务路由匹配）、EMITS/LISTENS_ON（通道检测）、DATA_FLOWS（数据流追踪）、SIMILAR_TO（克隆检测）、SEMANTICALLY_RELATED（语义关联）。

🔍 语义向量搜索

nomic-embed-code 768维 int8 向量编译进二进制——搜索「retry」能找到 publish/emit/dispatch。融合 11 种信号排名，无需 API Key。

📊 变更影响分析

detect_changes 将 git diff 映射到受影响符号及爆炸半径，附带风险分类。后台 Watcher 自动增量索引，Louvain 社区发现生成架构视图。

🛠️ 14 MCP 工具 + Cypher

search_graph、trace_path、query_graph（Cypher 子集）、get_architecture、get_code_snippet、manage_adr 等。可选 3D 图可视化（localhost:9749）。

💡 技术亮点

1. 纯 C 单二进制架构，零依赖无服务器

所有库（yyjson、SQLite、LZ4、tree-sitter 158语言语法、nomic-embed-code 向量）编译时静态内嵌进一个二进制。MCP Server 单线程事件循环 + stdio JSON-RPC 2.0，Pipeline 异步执行不阻塞响应，Watcher 独立线程监听文件变更，SQLite WAL 模式支持并发读写。

2. 知识图谱存储：SQLite + WAL + FTS5 + 预编译语句缓存

每项目独立数据库，节点按 Qualified Name 全局唯一寻址并支持后缀匹配。FTS5 虚拟表对节点名建全文索引，预编译语句缓存实现亚毫秒查询。Upsert 语义保证增量索引幂等性。

3. 安全链：SLSA Level 3 + VirusTotal + CodeQL + Sigstore

每次发布经 70+ 杀毒引擎扫描（零检出要求），GitHub Actions 加密构建来源证明（SLSA 3），Sigstore cosign 无密钥签名，CodeQL SAST 阻断存在未解决告警的发布——工业级安全标准。
