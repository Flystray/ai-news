📌 项目背景

2025年初，DeepSeek R1 的发布震动了整个 AI 界——一个开源模型通过"推理时思考"实现了与闭源模型媲美的能力。随后 OpenAI o1/o3、GPT-5 Thinking 等现象级产品的涌现，让"推理模型"成为 LLM 领域最炙手可热的方向。

但问题来了：大多数开发者只能调用 API，对推理模型内部机制一知半解。GRPO 强化学习、推理时扩展、知识蒸馏——这些术语满天飞，但真正理解并能亲手实现的人少之又少。

reasoning-from-scratch 正是为解决这个痛点而生。它由世界级 AI 教育者 Sebastian Raschka 博士撰写，是 Manning 出版社发行的《Build a Reasoning Model (From Scratch)》一书的官方配套代码仓库。项目的核心哲学简单直接：最好的学习方法就是亲手构建。

"这本书不仅解释推理模型，还让你能够从第一性原理构建、测试和真正理解它们。"
—— Aman Chadha, Google DeepMind 高级技术主管
"我见过的关于推理模型最好的资源之一。"
—— Ivan Leo, Google DeepMind 技术团队

Raschka 此前已凭借《Build a Large Language Model (From Scratch)》（⭐ 34k+）成为 LLM 教育领域的标杆人物。这本新书是他的进阶之作——在 LLM 基础上叠加推理能力。截至2026年6月，项目已获得 4,474 Stars、659 Forks，288 次提交，配套 PyPI 包可一键安装。

🚀 核心功能

1. 渐进式八章学习路径

以交互式 Jupyter Notebook 为载体，从零开始逐步培养推理模型开发能力：

章节主题核心收获
Ch1理解推理模型建立完整技术路线图认知
Ch2文本生成基础使用 Qwen3 进行文本生成，搭建环境
Ch3评估推理模型构建 MATH-500 评估框架
Ch4推理时扩展基础思维链、自一致性、多数投票
Ch5高级推理时扩展自我优化、Best-of-N 采样
Ch6GRPO 强化学习基础从零实现 GRPO 训练循环
Ch7高级 GRPO 优化DeepSeek-V3.2/Olmo3 风格多变体实现
Ch8知识蒸馏推理模型蒸馏数据生成与训练

每章配有习题解答，形成"阅读→编码→练习"三步学习闭环。

2. 六大附录——从源码到生产

  • 附录 C：Qwen3 完整源码——从零构建 Transformer，连接教学代码与真实开源模型
  • 附录 D：使用更大规模 LLM——将推理方法扩展到更大模型
  • 附录 E：批处理与吞吐量优化——生产环境性能调优
  • 附录 F：LLM 评估方法大全——MMLU、排行榜、LLM-as-a-Judge
  • 附录 G：构建聊天界面——为推理模型搭建 Chat UI

3. GRPO 强化学习——DeepSeek R1 核心技术完整实现

GRPO 是 DeepSeek R1 取得突破性推理能力的关键技术。本书用整整两章（Ch6 + Ch7）从零实现：

  • Ch6：基础 GRPO 训练循环，奖励函数设计、策略优化基础
  • Ch7：高级 GRPO 技巧，KL 散度约束、DeepSeek-V3.2 和 Olmo3 风格多变体
  • 配套资源：HuggingFace 上提供 GRPO 训练检查点供直接下载实验

4. 推理时扩展全景覆盖

Ch4-Ch5 系统覆盖推理时扩展的完整技术栈：

  • 思维链（CoT）：引导模型生成中间推理步骤
  • 自一致性（Self-Consistency）：多路径投票选出最佳答案
  • 自我优化（Self-Refinement）：模型审视并迭代改进自己的输出
  • Best-of-N：N 个候选结果选择最优解

这些方法在不改变模型权重的前提下，通过"多想一想"显著提升数学推理能力。

5. 知识蒸馏——把小模型变成推理高手

第 8 章聚焦推理模型蒸馏：使用大型推理模型（教师）生成高质量推理数据集，通过蒸馏训练将推理能力迁移到小型模型（学生）。蒸馏后模型在保持小体积的同时获得远超同规模的推理能力。

⚙️ 技术亮点

1. 三层架构：教学性 × 生产级代码质量

项目在"易于理解"和"代码规范"之间取得精妙平衡：

  • 教育内容层（.ipynb）：逐行解释每一步操作和原理
  • 核心实现层（Python 模块）：Qwen3、分词器、GRPO 循环独立可复用
  • 质量保障层：CI 流水线覆盖三平台 + Python 3.10-3.13

2. 消费级硬件友好——人人可复现

项目设计底线是消费级硬件可运行：Ch2-Ch4 纯 CPU 可执行；Ch5-Ch7 推荐 GPU 但自动回退；基础模型选用 Qwen3 而非超大模型；所有代码在生产级硬件上验证可运行。

3. 与前沿模型的"原理对齐，非复现"

项目不是去复现 DeepSeek R1 的完整训练，而是通过亲手实践让你真正理解驱动这些前沿模型的核心原理：

前沿模型本书覆盖的核心技术

GPT-5 Thinking推理时扩展、自我优化

⚡ 快速上手

# 1. 克隆仓库
git clone --depth 1 https://github.com/rasbt/reasoning-from-scratch.git
cd reasoning-from-scratch

# 2. 安装依赖
pip install -r requirements.txt

# 3. 安装 PyPI 包（可选）
pip install reasoning-from-scratch

# 4. 从 Ch2 开始学习
jupyter notebook ch02/ch02_main.ipynb

硬件建议：前4章 CPU 即可；GrPO 训练（Ch6-Ch7）推荐 GPU。代码自动检测可用设备。

⚠️ 使用注意

建议先完成 Raschka 的《LLMs-from-scratch》或具备同等 LLM 基础再上手本书，否则在 Transformer 架构、注意力机制等前置知识上会卡住。
  • 建议按章节顺序学习：每章都建立在前一章基础上，跳章可能导致概念断层
  • Notebook 可能较大：Ch6-Ch7 的 GRPO 训练章节建议在 Colab 或云 GPU 上运行
  • 不接收主线代码 PR：因代码与纸质书籍强绑定，作者暂不接收修改主章节代码的贡献
  • 配套书籍推荐购买：代码仓库虽有完整实现，但书籍中的详细解释和原理阐述无可替代
