📌 项目背景

2026 年，端侧 AI 的拐点已经到来。过去两年，大模型的主流部署方式一直是"云端 API"——把用户的 prompt 发到远程服务器，等几百毫秒再拿回结果。这套模式有三大结构性困境：网络延迟不可控（100–500ms 起步）、数据隐私难保障（所有输入都离开设备）、成本随用量线性累积。

与此同时，2025–2026 年发布的旗舰芯片 NPU 算力已经突破 40 TOPS：高通骁龙 X Elite（45 TOPS）、Apple M4（38 TOPS）、Intel Lunar Lake NPU（48 TOPS）相继落地。硬件已经就位，缺的是能真正把这些算力用起来的软件框架。

LiteRT-LM 是 Google AI Edge 团队推出的生产级、开源、跨平台 LLM 推理框架，也是 TensorFlow Lite 的直接继承者——但这次，是为大型语言模型从底层重新设计的。

💡 TensorFlow Lite 为什么不够用了？

TensorFlow Lite 的架构是为 CNN、RNN 等小模型（<100MB）设计的：静态计算图、批量推理、无 KV Cache 支持。这些设计在 LLM 时代全部成为瓶颈。LiteRT-LM 原生支持动态长度序列、自回归推理、KV Cache、流式 token 生成——这些都是 Transformer 推理的基本需求。

🚀 核心功能

1. 跨平台推理支持

覆盖从数据中心到指尖的全场景：Android（稳定）、iOS（开发中）、Web/Wasm/WebGL（稳定）、Linux/macOS/Windows（WSL）、Raspberry Pi 等 ARM 嵌入式设备。

2. 多级硬件加速

GPU 加速（Adreno / Mali / Apple GPU）、NPU 加速（Hexagon / Apple Neural Engine / 联发科 NPU）、CPU 优化（ARM NEON / SIMD 深度优化）。

3. 多模态能力

支持文本、图片（图表、文档）、语音音频流（Gemma Vision、Qwen2-VL、Gemma 3n 语音模型）。一套框架覆盖三种模态。

4. 原生工具调用（Tool Use / Function Calling）

原生支持函数调用、结构化 JSON 输出、LGuidance 语法约束，以及 RAG 内置支持。Agentic Workflow 可直接在端侧运行。

5. 四级量化体系

FP16 → INT8（<1% 精度损失）→ INT4（3–8%，3.5GB/7B 模型） → INT2。支持 GPTQ、AWQ 等先进量化算法。

6. KV Cache 量化与分页管理

支持 KV Cache INT8 量化，以及类操作系统的分页 KV Cache（Paged KV Cache）：以 16 个 token 为一块，支持 LRU 淘汰策略。内存利用率提升约 60%。

7. 分层内存池（EdgeMemoryManager）

三层设计：高速缓存池（<1MB，延迟 <1ns）→ 主内存池（8–16GB）→ 存储池（>64GB）。实测：内存占用减少 40%，推理延迟提升 2.5×，能耗降低 60%。

8. 算子融合（Kernel Fusion）

整个 Attention 融合为单次 CUDA/Metal/Vulkan 核函数调用，HBM 读写从 4 次降至 2 次。结合 Flash Attention 2/3，长序列性能提升 10× 以上。

9. 多语言 API

Kotlin（生产就绪）、Python（nanobind）、C++（高性能）、Swift（即将发布）、C API、Rust 绑定。

10. 专有格式 + HuggingFace 直接加载

使用 .litertlm 专有格式，也支持从 HuggingFace 仓库直接加载，无需手动转换。

⚙️ 技术亮点

亮点一：唯一支持 WebGPU 的 LLM 推理引擎

通过 WebGPU + WASM，直接在浏览器里运行 LLM，零服务器成本、零网络延迟。Chrome 134 + RTX 4070 Laptop GPU 实测：Gemma-2B INT4 可达 42 tokens/s，Qwen2-1.5B INT4 达 78 tokens/s。延迟压缩到 <10ms，且完全免费。

亮点二：与 llama.cpp 的直接性能对比

CPU 解码速度比 llama.cpp 快约 3×，GPU 模式快约 7×，NPU 预填充阶段额外提升约 3×。

亮点三：三级内存池的工程价值

Pixel 9 Pro（Tensor G4）+ Gemma-4B INT4 实测：内存峰值占用仅 2.8GB，持续生成 18 tokens/s——端侧 LLM 框架第一梯队表现。

🛠️ 快速上手

CLI 尝鲜：

uv tool install litert-lm

litert-lm run   --from-huggingface-repo=google/gemma-3n-E2B-it-litert-lm   gemma-3n-E2B-it-int4   --prompt="解释一下 Transformer 架构"

Python：

pip install litertlm
from litertlm import Model
model = Model.from_huggingface("google/gemma-3n-E2B-it-litert-lm")
result = model.generate("法国的首都是哪里？")
print(result.text)

Android Kotlin：

dependencies { implementation("com.google.ai.edge.litert:litert:0.10.1") }

val model = Model.fromFile("gemma-3n-e2b-it.litertlm")
val response = model.generate("法国的首都是哪里？")
println(response.text)
