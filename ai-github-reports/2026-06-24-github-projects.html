📌 项目背景

AI 视频生成工具遍地开花——Sora、Kling、Veo、Runway——但本质上都是「输入一句话，吐出一段片段」的单步生成器。真正做视频从来不是这么简单：你需要选题调研、写脚本、做分镜、找素材、配音配乐、上字幕、剪辑渲染，最后还要检查黑帧、音量、画面是不是像 PPT。

OpenMontage 提出截然不同的思路：它不是再造一个网页生成器，而是把 Claude Code、Cursor、Copilot、Windsurf 这类 AI 编程助手当作「导演」，让它读 Pipeline 清单、按阶段执行 Skill、调用 Python 工具、写检查点、自审质量——完成从调研到成片的端到端自动化。项目 3 个月斩获 17,300+ Stars、2,000+ Forks，源码超 3.4M 字符。

🚀 七大核心功能

1. Agent-First 架构

没有 Python 编排器——AI Agent 本身就是控制平面。Python 只提供工具层、注册表和检查点，生产规则写在 YAML 和 Markdown 中。一切可读可审计。

2. 12 条生产 Pipeline

Animated Explainer、Cinematic、Documentary Montage、Clip Factory、Podcast Repurpose 等，每条有独立 8 阶段流程 + 专属 Stage Director + 审查重点。

3. Provider Selector 智能路由

7 维度加权评分引擎（task_fit 30%、quality 20%、control 15%、reliability 15%、cost 10%、latency 5%、continuity 5%），动态选最优 Provider。

4. 52+ 工具 × 30+ Provider

视频生成 14+ Provider、图像生成 10+ Provider、TTS 5+ Provider、分析增强字幕等。全部 BaseTool 统一契约，ToolRegistry 自动发现。

5. 双渲染引擎 + 真实素材路径

Remotion（React 数据驱动）+ HyperFrames（HTML/GSAP 动态排版）。支持 Archive.org/NASA/Wikimedia 真实素材时间线，不是「动画 PPT」。

6. 质量治理四层门禁

Pre-compose validation + Slideshow risk scoring + Post-render self-review + Source media inspection。防止「看起来像视频的 PPT」。

7. 零成本可用路径

Piper TTS（离线免费）+ Pexels/Pixabay/Unsplash（免费素材）+ WAN 2.1/Hunyuan/CogVideo（本地 GPU）+ Remotion/HyperFrames。两条免费路径。

💡 三大技术亮点

1. 三层知识架构：意图 → 约定 → 技术

Layer 1（pipeline_defs + tools）定义「有哪些能力」，Layer 2（skills）定义「如何使用 + OpenMontage 质量标准」，Layer 3（.agents/skills）定义「外部技术怎么工作」。工具通过 agent_skills[] 自动关联知识包——Agent 从不临场发挥："The intelligence is in the skills, not in improvised code"。

2. Checkpoint 状态机：可恢复、可审计、可移交

每阶段完成写 checkpoint.json，包含规范产物（research_brief、edit_decisions 等），JSON Schema 验证。LLM 上下文重置、Agent 换人、生产中断——都可从最近 checkpoint 恢复。

3. 跨 IDE 统一配置

CLAUDE.md、CURSOR.md、COPILOT.md、CODEX.md、.windsurfrules 全指向共享 AGENT_GUIDE.md 和 PROJECT_CONTEXT.md，无论用哪个 AI 编程助手，Pipeline/Skill/工具逻辑完全一致。
