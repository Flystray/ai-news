把 LLM 装进口袋：Google LiteRT-LM 开启端侧推理新纪元

今日推荐 · Google 端侧 LLM 推理框架 · 2026-05-02

今天推荐一个 Google 刚推出不久、但已经被集成到数百万真实设备上的开源项目：LiteRT-LM——把大模型真正跑在手机、浏览器和嵌入式设备上的生产级推理框架。

为什么值得关注？

过去两年，大模型的主流部署方式是"云端 API"：把 prompt 发到远程服务器，等几百毫秒拿回结果。这有三大问题：网络延迟不可控（100–500ms 起步）、隐私难保障（数据全离设备）、成本随用量线性增长。

与此同时，2025–2026 年的旗舰芯片 NPU 算力已突破 40 TOPS：高通骁龙 X Elite（45 TOPS）、Apple M4（38 TOPS）、Intel Lunar Lake NPU（48 TOPS）。硬件就位了，缺的是能真正用起来的软件。

LiteRT-LM 就是这个答案。它是 TensorFlow Lite 的正式继任者，但这次是为 LLM 从底层重新设计的——TensorFlow Lite 的架构（静态图、批量推理、无 KV Cache）完全不适合 LLM。

LiteRT-LM 的核心定位：生产级、开源、跨平台（Android/iOS/Web/桌面/IoT）的端侧 LLM 推理引擎，已在 Chrome、Chromebook Plus、Pixel Watch 等数百万真实设备上验证。

十大核心功能

1. 跨平台覆盖：Android（稳定）、iOS（开发中）、Web/Wasm（稳定）、Linux/macOS/Windows（WSL）、Raspberry Pi

2. 多级硬件加速：GPU（Adreno/Mali/Apple GPU）+ NPU（Hexagon/Apple Neural Engine）+ CPU（ARM NEON/SIMD）

3. 多模态能力：文本 + 图片（图表/文档）+ 语音，一套框架全支持

4. 原生工具调用：函数调用、结构化 JSON、LGuidance 约束、RAG，Agentic Workflow 端侧直跑

5. 四级量化体系：FP16 → INT8（<1% 损失）→ INT4（3–8% 损失，7B 模型仅 3.5GB） → INT2

6. KV Cache 量化 + 分页管理：INT8 量化 KV Cache，分页管理（16 token/块，LRU 淘汰），内存利用率提升 60%

7. 三层内存池（EdgeMemoryManager）：热点数据（<1MB，<1ns）→ 主内存（8–16GB）→ 存储池（>64GB），实测内存减少 40%、延迟提升 2.5×、能耗降低 60%

8. 算子融合：Attention 全链路融合为单次核函数，HBM 读写 4 次→2 次，长序列性能提升 10×+

9. 多语言 API：Kotlin（生产）、Python（nanobind）、C++、Swift（即将）、Rust

10. HuggingFace 直接加载：无需手动转换，API 直接指定 HuggingFace 仓库即可

三个技术亮点

亮点1：唯一支持 WebGPU 的端侧 LLM 引擎
通过 WebGPU + WASM，直接在浏览器里跑 LLM，零服务器成本、零网络延迟。对 Web AI 应用（实时翻译、代码补全）是颠覆性能力。

亮点2：三级内存池的精细工程
端侧内存带宽是主要瓶颈（移动端 LPDDR5X ~68 GB/s，远低于服务端 DDR5 的 ~400 GB/s）。三层池设计（pin 热点在 SRAM → 激活值预取 → 备用权重 DMA 换入）是关键突破。

亮点3：生产级验证
不是实验室项目——已集成 Chrome、Chromebook Plus、Pixel Watch，在数百万真实设备上运行。这是开源社区少数几个真正生产就绪的端侧 LLM 框架之一。

适用人群

  • 移动应用开发者（Android/iOS App 离线程 AI）
  • 隐私敏感应用（医疗健康、金融，数据不离设备）
  • Web 开发者（浏览器 AI 能力，零成本部署）
  • 边缘计算工程师（IoT 设备，智能家居/工业物联网）
  • LLM 推理优化研究人员

快速上手

CLI 尝鲜（推荐）：

uv tool install litert-lm

litert-lm run   --from-huggingface-repo=google/gemma-3n-E2B-it-litert-lm   gemma-3n-E2B-it-int4   --prompt="解释一下 Transformer 架构"

Python：

pip install litertlm
from litertlm import Model
model = Model.from_huggingface("google/gemma-3n-E2B-it-litert-lm")
print(model.generate("法国的首都是哪里？").text)

Android：

dependencies { implementation("com.google.ai.edge.litert:litert:0.10.1") }

val model = Model.fromFile("gemma-3n-e2b-it.litertlm")
val response = model.generate("法国的首都是哪里？")
println(response.text)
